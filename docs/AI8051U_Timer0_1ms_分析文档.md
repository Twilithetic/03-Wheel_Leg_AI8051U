## 一、问题描述

如何在 AI8051U 单片机上配置 Timer0 实现 **1ms 精确定时**，用于系统节拍（SysTick）或其他周期性任务。

## 二、Timer0 相关寄存器全览

### 2.1 特殊功能寄存器（SFR：0x80-0xFF）

| 寄存器 | 地址 | 复位值 | 位定义 | 说明 |
|--------|------|--------|--------|------|
| **TCON** | 88H | 0000,0000 | TF1, TR1, TF0, TR0, IE1, IT1, IE0, IT0 | 定时器控制寄存器 |
| **TMOD** | 89H | 0000,0000 | T1_GATE, T1_C/T, T1_M1, T1_M0, T0_GATE, T0_C/T, T0_M1, T0_M0 | 定时器模式寄存器 |
| **TL0** | 8AH | 0000,0000 | TMR0[7:0] | Timer0 低 8 位计数寄存器 |
| **TH0** | 8CH | 0000,0000 | TMR0[15:8] | Timer0 高 8 位计数寄存器 |
| **AUXR** | 8EH | 0000,0001 | **T0x12**, T1x12, UART_M0x6, T2R, T2_C/T, T2x12, EXTRAM, S1BRT | 辅助寄存器1（含时钟分频控制） |
| **INTCLKO** | 8FH | x000,x000 | -, EX4, EX3, EX2, -, T2CLKO, T1CLKO, **T0CLKO** | 中断与时钟输出控制 |
| **IE** | A8H | 0000,0000 | **EA**, ELVD, EADC, ES, ET1, EX1, **ET0**, EX0 | 中断允许寄存器 |

### 2.2 扩展特殊功能寄存器（XFR）

| 寄存器 | 地址 | 复位值 | 说明 |
|--------|------|--------|------|
| **TM0PS** | 7EFEA0H | 0000,0000 | Timer0 8 位时钟预分频寄存器 |

> ⚠️ **重要**：TM0PS 属于扩展寄存器（XFR），访问前必须先设置 **EAXFR = 1**（32位模式）或 **P_SW2 \|= 0x80**（8位模式）。

### 2.3 各寄存器位的详细功能

#### TCON（88H）—— 定时器控制寄存器

```
Bit:  7     6     5     4     3     2     1     0
     TF1   TR1   TF0   TR0   IE1   IT1   IE0   IT0
```

| 位 | 名称 | 功能 |
|----|------|------|
| **TR0** | Timer0 运行控制 | 软件置1启动T0计数；软件清0停止T0计数 |
| **TF0** | Timer0 溢出标志 | T0溢出时硬件置1，CPU响应中断后硬件清0（也可软件查询清0） |

> 启动条件：当 `GATE(TMOD.3)=0` 时，`TR0=1` 即启动；当 `GATE=1` 时，需 `TR0=1` **且** `INT0` 引脚为高电平才启动。

#### TMOD（89H）—— 定时器模式寄存器

```
Bit:  7         6        5      4      3         2        1      0
     T1_GATE  T1_C/T  T1_M1  T1_M0  T0_GATE  T0_C/T  T0_M1  T0_M0
```

Timer0 相关位（低4位）：

| 位 | 名称 | 功能 |
|----|------|------|
| T0_GATE | 门控位 | 0: 仅TR0控制启停；1: TR0+INT0引脚共同控制 |
| **T0_C/T** | 定时/计数选择 | **0: 定时器**（对内部系统时钟计数）；1: 计数器（对外部引脚脉冲计数） |
| **T0_M1, T0_M0** | 工作模式选择 | 见下表 |

**T0 工作模式表：**

| M1 | M0 | 模式 | 说明 |
|----|----|------|------|
| 0 | 0 | **模式0** | **16位自动重装载** — 溢出后自动从隐藏重载寄存器恢复初值 |
| 0 | 1 | 模式1 | 16位不可重装载 — 溢出后从0开始计数 |
| 1 | 0 | 模式2 | 8位自动重装载 — TL0溢出后从TH0重装 |
| 1 | 1 | 模式3 | **不可屏蔽中断的16位自动重装载** — 中断优先级最高，不受EA/ET0控制 |

> 📌 **推荐使用模式0**来作为普通1ms定时器，模式3用于RTOS系统节拍。

#### AUXR（8EH）—— 辅助寄存器1

```
Bit:  7       6       5           4     5       3       2       1       0
     T0x12  T1x12  UART_M0x6   T2R  T2_C/T  T2x12  EXTRAM  S1BRT
```

| 位 | 名称 | 功能 |
|----|------|------|
| **T0x12** (bit7) | Timer0 时钟分频 | **0: 12T模式**（系统时钟/12计数）；**1: 1T模式**（系统时钟直接计数，快12倍） |

#### INTCLKO（8FH）—— 时钟输出控制

| 位 | 名称 | 功能 |
|----|------|------|
| T0CLKO (bit0) | Timer0 时钟输出使能 | 1: P3.5/T1 引脚输出 T0 溢出率/2 的时钟 |

## 三、AI8051U Timer0 架构特点

### 3.1 24位定时器架构

AI8051U 的 Timer0 支持 **8位预分频 + 16位计数 = 24位定时器**：

```
SYSclk ──→ [TM0PS+1 预分频] ──→ [T0x12 1T/12T] ──→ [TH0:TL0 16位加法计数器] ──→ TF0溢出中断
              (8位, 1~256)           (÷1 或 ÷12)            (0~65535)
```

- **TM0PS=0**：不分频，T0 为 16 位定时器
- **TM0PS=n (1~255)**：n+1 分频，T0 变为 24 位定时器

### 3.2 定时器输入时钟计算

| T0x12 | 分频因子 | 定时器输入时钟频率 |
|-------|---------|-------------------|
| 0 (12T) | 12 | `SYSclk / (TM0PS+1) / 12` |
| 1 (1T) | 1 | `SYSclk / (TM0PS+1) / 1` |

### 3.3 隐藏重载寄存器

当 Timer0 工作在自动重装载模式（模式0/模式3）时：
- 写入 **TH0/TL0** 的同时会写入隐藏的重载寄存器 **RL_TH0/RL_TL0**
- 溢出时自动从 RL_TH0/RL_TL0 恢复初值到 TH0/TL0
- 读取 TH0/TL0 读到的是当前计数值，而非重载值

## 四、1ms 定时配置（核心）

### 4.1 官方公式

手册第 1078 页的官方示例代码：

```c
#define Timer0_Reload (65536UL - (MAIN_Fosc / 1000))  // Timer0 中断频率 = 1000Hz
```

### 4.2 数学推导

**以典型配置为例：** MAIN_Fosc = 24MHz, T0x12 = 1 (1T模式), TM0PS = 0 (不分频)

```
定时器输入时钟频率 = MAIN_Fosc / (TM0PS+1) / 1 = 24,000,000 Hz
每个计数周期      = 1 / 24,000,000 秒 ≈ 41.67 ns
1ms 需要的计数    = 24,000,000 / 1,000 = 24,000 次

重载值 = 65536 - 24000 = 41536 (0xA240)

即：TH0 = 0xA2, TL0 = 0x40
```

**验证：**
```
溢出时间 = 计数次数 / 定时器输入频率 = 24000 / 24,000,000 = 0.001 秒 = 1ms ✓
```

### 4.3 不同时钟频率下的重载值

| 主频 MAIN_Fosc | T0x12 | 预分频 TM0PS | 重载值公式 | 重载值(十进制) | TH0 | TL0 |
|---------------|-------|-------------|-----------|-------------|-----|-----|
| 24 MHz | 1 | 0 | 65536-24000 | 41536 | 0xA2 | 0x40 |
| 22.1184 MHz | 1 | 0 | 65536-22118 | 43418 | 0xA9 | 0x9A |
| 12 MHz | 1 | 0 | 65536-12000 | 53536 | 0xD1 | 0x20 |
| 11.0592 MHz | 1 | 0 | 65536-11059 | 54477 | 0xD4 | 0xCD |
| 40 MHz | 1 | 0 | 65536-40000 | 25536 | 0x63 | 0xC0 |
| 24 MHz | 0 (12T) | 0 | 65536-2000 | 63536 | 0xF8 | 0x30 |

> 📌 **推荐配置**：使用 1T 模式（T0x12=1），精度更高，定时器输入频率 = 主频，计算更方便。

### 4.4 使用预分频器扩展定时范围

如果需要更长的定时时间（如 100ms），可以让 TM0PS 参与分频：

```
TM0PS = 23 (即 24 分频):
定时器输入 = 24MHz / 24 = 1MHz
1ms 计数 = 1,000,000 / 1,000 = 1000
重载值 = 65536 - 1000 = 64536

// 或者 100ms:
100ms 计数 = 1,000,000 / 10 = 100,000 > 65536 → 无法单次完成
→ 可以设置 10ms 中断，配合软件计数器累计
```

## 五、完整配置代码示例

### 5.1 最小化 1ms 定时（16位，模式0，1T模式）

```c
#include "Ai8051U.H"

#define MAIN_Fosc     24000000L                          // 系统主频 24MHz
#define Timer0_Reload (65536UL - (MAIN_Fosc / 1000))     // 1ms 重载值

bit B_1ms;  // 1ms 标志位

//========================================================================
// 函数: Timer0_config()
// 描述: Timer0 初始化，1ms 定时 (模式0, 16位自动重装载, 1T)
//========================================================================
void Timer0_config(void)
{
    TMOD &= 0xF0;                         // 清除 T0 模式位 (低4位清0)
                                          // M1=0, M0=0 → 模式0: 16位自动重装载
    TMOD &= ~0x04;                        // T0_C/T = 0 → 定时器模式
    TMOD &= ~0x08;                        // T0_GATE = 0 → 仅由 TR0 控制

    T0x12 = 1;                            // AUXR.7: 1T 模式 (不分频)

    TH0 = (unsigned char)(Timer0_Reload / 256);
    TL0 = (unsigned char)(Timer0_Reload % 256);

    ET0 = 1;                              // IE.1: 允许 Timer0 中断
    TR0 = 1;                              // TCON.4: 启动 Timer0
}

//========================================================================
// 函数: timer0() interrupt 1
// 描述: Timer0 中断服务函数
//========================================================================
void timer0(void) interrupt 1
{
    B_1ms = 1;  // 设置 1ms 标志
}

//========================================================================
// 函数: main()
//========================================================================
void main(void)
{
    Timer0_config();
    EA = 1;  // 开总中断

    while (1)
    {
        if (B_1ms)
        {
            B_1ms = 0;
            // 在这里执行每 1ms 需要处理的逻辑
        }
    }
}
```

### 5.2 24位定时器配置（带预分频）

```c
#include "Ai8051U.H"

#define MAIN_Fosc     24000000L

// 使用 TM0PS=23 (24分频)，1T模式
// 定时器输入 = 24MHz / 24 = 1MHz
// 1ms 计数 = 1000
#define Timer0_Reload (65536UL - 1000)

static bit B_1ms;

void Timer0_config(void)
{
    EAXFR = 1;                            // 使能扩展寄存器访问（32位模式）
    // P_SW2 |= 0x80;                     // 或使用 8 位模式访问

    TM0PS = 23;                           // 预分频器 = 23+1 = 24分频

    TMOD &= 0xF0;                         // T0: 模式0, 16位自动重装载
    T0x12 = 1;                            // 1T 模式

    TH0 = (unsigned char)(Timer0_Reload / 256);
    TL0 = (unsigned char)(Timer0_Reload % 256);

    ET0 = 1;
    TR0 = 1;
}

void timer0(void) interrupt 1
{
    B_1ms = 1;
}
```

### 5.3 模式3 - 不可屏蔽中断（RTOS系统节拍）

```c
// 模式3特点：中断优先级最高，不受 EA/ET0 控制，一旦打开无法关闭
// 适用于 RTOS 系统节拍定时器

void Timer0_config_mode3(void)
{
    TMOD &= 0xF0;
    TMOD |= 0x03;                         // M1=1, M0=1 → 模式3: 不可屏蔽16位自动重装载

    T0x12 = 1;                            // 1T 模式

    TH0 = (unsigned char)(Timer0_Reload / 256);
    TL0 = (unsigned char)(Timer0_Reload % 256);

    ET0 = 1;                              // 打开中断（注意：模式3下 EA 不需要置1）
    TR0 = 1;                              // 启动定时器

    // 一旦 TR0=1 且 ET0=1，此中断无法被关闭
    // EA 和 ET0 的状态都不再影响它
}
```

## 六、关键注意事项

### 6.1 访问扩展寄存器
- TM0PS 位于扩展地址空间（7EFEA0H），访问前必须设 `EAXFR = 1`（32位模式）
- 或 `P_SW2 |= 0x80`（8位模式，兼容传统8051）

### 6.2 TMOD 安全写入
- 写入 TMOD 时注意保留 Timer1 的高4位配置：`TMOD &= 0xF0; TMOD |= newT0Bits;`
- 不要直接 `TMOD = 0x00;`，这会把 T1 配置也清零

### 6.3 T0_C/T 选择
- `T0_C/T = 0`：**定时器**模式，对内部系统时钟计数 → 做1ms定时用这个！
- `T0_C/T = 1`：**计数器**模式，对外部引脚 T0/P3.4 脉冲计数

### 6.4 模式3的特殊性
- 模式3的中断是**不可屏蔽**的，优先级**最高**
- 一旦启动（TR0=1, ET0=1），**EA 和 ET0 都不能再关闭此中断**
- 适用于 RTOS 系统节拍，普通应用**推荐使用模式0**

### 6.5 GATE 门控
- 默认 `T0_GATE = 0`，仅由 TR0 控制启停
- 若设为 `T0_GATE = 1`，需同时满足 `TR0=1` **且** `INT0(P3.2)高电平` 才计数
- 可用于脉宽测量等场景

## 七、与标准8051的差异

| 特性 | 传统8051 | AI8051U |
|------|---------|---------|
| 定时器位数 | 16位 | **24位**（8位预分频 + 16位计数） |
| 时钟分频 | 仅12T | 1T / 12T 可选 |
| 预分频寄存器 | 无 | **TM0PS** (7EFEA0H) |
| 模式3 | 将T0拆成两个8位定时器 | **不可屏蔽16位自动重装载**（RTOS节拍） |
| 指令集 | MCS-51 | **Intel 80251**（兼容 MCS-51） |
| 寄存器访问 | 仅SFR (0x80-0xFF) | SFR + XFR 扩展地址空间 |
