## 技术分析

### 1. PWM 硬件架构
- AI8051U 集成 **8通道 16位高级PWM定时器**，分两组：
  - **PWMA**（通道1-4）：可输出**互补/对称/带死区**的PWM，也可捕获外部信号
  - **PWMB**（通道5-8）：**单端PWM**输出或捕获，无死区功能
- PWMA 时钟源：系统时钟 → PWMA_PSCR 预分频器（1~65536分频）
- PWMB 时钟源：系统时钟 → PWMB_PSCR 预分频器（独立设置）
- 两组 PWM 可独立设置不同的周期和频率

### 2. 时基单元
- 16位向上/向下计数器（PWMA_CNTRH/L）
- 16位自动重载寄存器（PWMA_ARRH/L）
- 重复计数器（PWMA_RCR）
- 预分频器（PWMA_PSCRH/L）

### 3. 计数模式
| 模式 | CR1寄存器设置 | 说明 |
|------|---------------|------|
| 向上计数 | CMS=00, DIR=0 | 0→ARR，边沿对齐 |
| 向下计数 | CMS=00, DIR=1 | ARR→0，边沿对齐 |
| 中央对齐1 | CMS=01 | 上下计数，向下时置CCIF |
| 中央对齐2 | CMS=10 | 上下计数，向上时置CCIF |
| 中央对齐3 | CMS=11 | 上下计数，双向均置CCIF |

### 4. 频率计算公式
- **边沿对齐**：`f_PWM = SYSclk / ((PSCR+1) × (ARR+1))`
- **中央对齐**：`f_PWM = SYSclk / ((PSCR+1) × ARR × 2)`

### 5. PWM 输出模式（CCMR寄存器 OCxM位）
| OCxM[2:0] | 模式 |
|-----------|------|
| 100 | 强制输出无效电平 |
| 101 | 强制输出有效电平 |
| 110 | PWM模式1（CNT<CCR时有效） |
| 111 | PWM模式2（CNT>CCR时有效） |
