## 一、三个容易混淆的 `|= 0x80`

都是置 bit7，但打在三个不同的寄存器上，千万别搞混！

| 写法 | 寄存器 | 地址 | bit7 名称 | 作用 | 影响范围 |
|------|--------|:---:|----------|------|:---:|
| `EA \|= 0x80` | **IE** | 0xA8 | **EA** | 全局中断总开关 | 🔴 整栋楼 |
| `IE2 \|= 0x80` | **IE2** | 0xAF | **EUSB** | USB 中断分开关 | 🔵 仅 USB |
| `P_SW2 \|= 0x80` | **P_SW2** | 0xBA | **EAXFR** | 扩展寄存器访问 | 🟢 XFR 空间 |

### 记忆口诀

```
EA     → 总闸 → EA=0 一切中断全灭
EUSB   → USB闸 → 只管USB中断
EAXFR  → 钥匙门 → 不开门就碰不到高级外设寄存器
```

```
┌──────────────────────────────────────┐
│         EA = 1  (总闸)                │  IE 寄存器 bit7

├────────────┬─────────────────────────┤
│  标准中断   │       扩展中断           │
│ (IE 寄存器) │      (IE2 寄存器)        │
├────────────┼─────────────────────────┤
│ ET0 定时器0 │  EUSB  USB  ← IE2|=0x80 │
│ ET1 定时器1 │  ET4   定时器4           │

│ EX0 外部0  │  ES4   串口4            │

│ ELVD LVD  │  ESPI  SPI             │
│            │  ES2   串口2            │
└────────────┴─────────────────────────┘

中断触发条件：EA=1 且 对应位=1
```

## 三、AI8051U 地址空间全景

> 手册依据：AI8051U 芯片手册 §13（第613页）+ Intel 80251 编程指南 §3.1

### 3.1 Intel 80251 原始架构 —— 三个独立地址空间

```
         ╔═══════════════╗    ╔══════════════╗    ╔═══════════════╗
         ║ Memory Space  ║    ║  SFR Space   ║    ║Register File  ║
         ║  16MB 线性     ║    ║  512B 独立    ║    ║    64B        ║
         ║ FF:0000~FF:FFFF║   ║ S:000h~S:1FFh ║    ║  R0~R7×4组   ║
         ╚═══════╤═══════╝    ╚══════╤═══════╝    ╚═══════╤═══════╝
                 │                    │                     │
            MOV / MOVC           DIR 指令             寄存器操作
         (取指/读数据)        (直接寻址 SFR)        (BANK 切换)
```

三个空间**完全独立**，用不同指令区分。同一个地址 `80H`：
- 在 Memory Space → 访问 edata RAM 地址 80H
- 在 SFR Space → 访问 P0 端口寄存器
- 在 Register File → 不存在（Register File 只有 00H~1FH）

### 3.2 AI8051U 24位线性地址空间全貌

STC 把 80251 的三个独立空间**全部压缩到一根 24 位地址总线上**：

```
┌────────┬──────────────────────┬───────────────────────────────┐
│ 地址范围  │       名称           │          里面有什么            │
├────────┼──────────────────────┼───────────────────────────────┤
│00:0000 │  data 低128B          │ Register File (R0~R7)         │
│   ~    │  (直接+间接寻址)       │ 00:00~00:1F = 4组工作寄存器    │
│00:007F │                       │ 00:20~00:2F = 位寻址区         │
│        │                       │ 00:30~00:7F = 普通 data RAM   │
├────────┼──────────────────────┼───────────────────────────────┤
│00:0080 │  ⭐ SFR 区 (直接)     │ ← 🎯 标准 SFR 在这里！         │
│   ~    │  + data 高128B (间接) │ P0(80H),SP(81H),DPL(82H)...   │
│00:00FF │                       │ IE(A8H),IP(B8H),P_SW2(BAH)... │
│        │  ← 共用同一段物理地址   │ 共 ~128个，全部支持位寻址       │
│        │  不同指令打到不同硬件！ │                               │
│        │                       │ ⚠️ 区分方式：                  │
│        │                       │ MOV 80H,A  → 写 SFR (P0)     │
│        │                       │ MOV @R0,A  → 写 data RAM     │
├────────┼──────────────────────┼───────────────────────────────┤
│00:0100 │  edata 扩展 RAM       │ 堆栈区 (SP/SPH)                │
│   ~    │  ~1.8KB              │ 用户变量 (XSmall模式默认放这)   │
│00:07FF │                       │ 单时钟 32bit 访问！             │
├────────┼──────────────────────┼───────────────────────────────┤
│01:0000 │  xdata SRAM          │ 内部扩展 RAM，实际 32KB         │
│   ~    │  32KB                │ 2~3 时钟访问 (比edata慢)        │
│01:7FFF │                       │ MOVX @DPTR 指令访问            │
├────────┼──────────────────────┼───────────────────────────────┤
│7E:0000 │  ⭐ XFR 扩展 SFR 区   │ ← 🎯 扩展 SFR 在这里！         │
│   ~    │  (STC 独创)           │ 🔒 默认锁死，需 EAXFR=1        │
│7E:FFFF │                       │ 7E:FE00~FEFF → 时钟,PLL,PWM  │
│        │                       │ 7E:FD00~FDFF → 端口中断        │
│        │                       │ 7E:FB00~FBFF → SPI,CHIPID    │
│        │                       │ 7E:FA00~FAFF → DMA            │
│        │                       │ 通过 MOVX @DRk 指令访问        │
├────────┼──────────────────────┼───────────────────────────────┤
│7F:0000 │  外部 xdata 区        │ 🔒 需 EXTRAM=1 使能            │
│   ~    │  64KB                │ P0/P2/WR/RD/ALE 引脚才生效     │
│7F:FFFF │                       │                               │
├────────┼──────────────────────┼───────────────────────────────┤
│FF:0000 │  Code / Flash        │ ← 你的程序在这里！              │
│   ~    │  64KB                │ FF:0000 = 复位入口              │
│FF:FFFF │                       │ FF:0003 = INT0 中断向量        │
└────────┴──────────────────────┴───────────────────────────────┘
```

### 3.3 SFR vs XFR 对比速查

| | **标准 SFR** | **扩展 XFR** |
|:---|:---|:---|
| **逻辑地址** | 00:0080H ~ 00:00FFH | 7E:0000H ~ 7E:FFFFH |
| **挂在哪个区域** | **edata** 低256字节 | **xdata 逻辑空间** 的 7E 段 |
| **访问指令** | `MOV 80H, A`（直接寻址） | `MOV @DRk, Rm`（MOVX 间接） |
| **需要使能吗** | ❌ 不需要 | ✅ 必须 `EAXFR=1` |
| **位寻址** | ✅ 全部支持 | ❌ 不支持 |
| **80251 对应** | SFR Space S:080h~S:0FFh | **STC 独创**，80251 没有 |
| **使能方式** | — | `P_SW2 \|= 0x80` 或 `EAXFR = 1` |

### 3.4 核心理解：同一个地址，不同指令 = 不同硬件

```
地址 00:0080H：

  MOV  80H, #55H    →  写入 P0 端口寄存器 (SFR)
                       ↑ 直接寻址 → 走 SFR 硬件

  MOV  R0, #80H
  MOV  @R0, #55H    →  写入 edata RAM 的 80H 字节
                       ↑ 间接寻址 → 走 SRAM
```

AI8051U 把三个独立空间全揉进一根 24 位总线，但 CPU 根据**指令类型**自动路由：
- **DIR**（直接寻址） → SFR 硬件
- **INDIR**（间接寻址） → data/edata SRAM
- **MOVX**（外部访问） → xdata/XFR 硬件
- **MOVC**（取指） → Flash 代码区

## 四、SYS_Init() 初始化顺序（重要！）

```c
void SYS_Init(void)
{
    EnableAccessXFR();      // ① 🔑 先开门！不开门后面全白搭
    AccessCodeFastest();    // ② 代码取指最快
    AccessIXramFastest();   // ③ XDATA 访问最快
    IAP_SetTimeBase();      // ④ 设置 IAP 时基

    P0~P5 端口初始化         // ⑤ 端口配置
    CLK_Init();             // ⑥ ⏰ 时钟（PLL→XFR空间，必须先开门！）
    WDT_Init();             // ⑦ 看门狗
    USBLIB_Init();          // ⑧ 🔌 USB（寄存器全在XFR空间）
    MATHLIB_Init();         // ⑨ 🧮 TFPU（浮点→XFR空间）

    EnableGlobalInt();      // ⑩ ✅ 最后开总中断！
    USBLIB_WaitConfiged();  // ⑪ 等 USB 枚举完成
}
```

## 五、USB HID vs CDC 速查

| | HID | CDC |
|------|-----|------|
| **免驱** | ✅ 即插即用 | ⚠️ Win需装驱动 |
| **传输模式** | 中断传输（固定周期） | 批量传输（有空才传） |
| **速度** | ~1.2KB/s (全速64B) | 更快（占满剩余带宽） |
| **printf 调试** | ❌ 不支持 | ✅ 虚拟串口 |
| **数据格式** | 有结构（Report） | 裸字节流 |
| **烧录推荐** | ✅ 省心！ | 调试用 |
| **库文件** | `stc_usb_hid_32g_xdata.lib` | `stc_usb_cdc_32g_xdata.lib` |
| **OutNumber** | ❌ 需自己定义 `BYTE xdata OutNumber;` | ✅ 库自带 |

**你的项目**：烧录用HID(`@STCISP#`)，printf用CDC，库文件用 `stc_usb_cdc_32g_xdata.lib`

## 六、常见错误速查

| 错误现象 | 原因 | 解决 |
|---------|------|------|
| `CLK_LIRC_WaitStable` 卡死 | LIRC 不需要，死循环等不到稳定标志 | 注释掉 clock.c:41-42 |
| `L127: OutNumber 未解析` | 链了HID库但代码用了CDC API | 改回 `stc_usb_cdc_32g_xdata.lib` |
| `L27: 中断帧不兼容` | HID库编译选项不一致 | 同上，切回 CDC 库 |
| 外设都不工作 | 忘了 `EnableAccessXFR()` | 确认 main.c:123 执行 |
