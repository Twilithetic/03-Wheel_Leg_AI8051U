## 0. 先说结论：之前的"方案 B"写错了！

宝贝你指出的问题完全正确！`beforeBuildTasks`/`afterBuildTasks` 是 unify_builder 在**编译前后**运行的脚本，**编译过程本身还是用 EIDE 配置的编译器**（SDCC 或 Keil_C51）。

```
❌ 错误理解：
  EIDE 编译 → afterBuildTask 跑 C251 脚本 → 搞定了
  问题：EIDE 编译用的还是 SDCC，afterBuildTask 只是额外操作

✅ 正确理解：
  EIDE 编译流程 = EIDE 配置的编译器（SDCC/Keil_C51）
  beforeBuildTask/afterBuildTask = 编译前后额外的脚本
  两者完全独立！
```

## 2. 真正的"方案 B"是什么？

方案 B 不是"加个 afterBuildTask"，而是**完全绕过 EIDE 的编译流程**。

### 2.1 方案 B 的三个层次

```
    EIDE（编辑器 + 项目管理）                  ← 还用它
         │
    ┌────┴────┐
    │          │
    ▼          ▼
  SDCC      ❌ 不用它编译了
  Keil_C51  ❌ 也不用
         │
         ▼
    ┌─────────────────┐
    │  自己的编译脚本   │  ← 方案 B 的核心
    │  ↓ C251.EXE     │
    │  ↓ L251.EXE     │
    │  ↓ OH251.EXE    │
    │  → AI8051U.hex  │
    └─────────────────┘
```

### 2.2 三个子方案

| 子方案 | 触发方式 | 复杂度 | EIDE 集成度 |
|--------|---------|--------|-----------|
| **B1: 命令行** | 终端手动输入 | ⭐ | 无 |
| **B2: 编译脚本** | `.\build.ps1` | ⭐⭐ | 低（终端运行） |
| **B3: VSCode Tasks** | `Ctrl+Shift+B` | ⭐⭐ | 中（集成到VSCode） |

### 2.3 子方案 B2 —— 编译脚本

```powershell
# build_c251.ps1
$C251 = "C:\Keil_v5\C251\BIN\C251.EXE"
$L251 = "C:\Keil_v5\C251\BIN\L251.EXE"
$SRC  = "src\main.c"
$OBJ  = "build\main.obj"
$HEX  = "build\AI8051U_test.hex"

Write-Host "Compiling..." -ForegroundColor Cyan
& $C251 $SRC INCDIR(src\STC) INCDIR(inc) OBJECT($OBJ) LARGE DEBUG SYMBOLS
if ($LASTEXITCODE -ne 0) { exit 1 }

Write-Host "Linking..." -ForegroundColor Cyan
& $L251 $OBJ TO $HEX
if ($LASTEXITCODE -ne 0) { exit 1 }

Write-Host "Done! HEX: $HEX" -ForegroundColor Green
```

### 2.4 子方案 B3 —— VSCode Tasks 集成

在 `.vscode/tasks.json` 添加：

```json
{
    "version": "2.0.0",
    "tasks": [
        {
            "label": "Build (Keil C251)",
            "type": "shell",
            "command": "C:\\Keil_v5\\C251\\BIN\\C251.EXE",
            "args": [
                "src\\main.c",
                "INCDIR(src\\STC)",
                "INCDIR(inc)",
                "OBJECT(build\\main.obj)",
                "LARGE",
                "DEBUG",
                "SYMBOLS"
            ],
            "group": {
                "kind": "build",
                "isDefault": true
            },
            "problemMatcher": []
        }
    ]
}
```

然后 `Ctrl+Shift+B` 就能编译。
