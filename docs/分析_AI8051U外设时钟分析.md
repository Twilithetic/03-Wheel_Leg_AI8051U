# AI8051U 外设时钟分析报告

> 基于《AI8051U芯片手册》第8章（时钟管理）及外设章节
> 文档来源: `docs/资料/资料_芯片外设_AI8051U芯片手册.pdf`

---

## 一、问题描述

需要了解 AI8051U 芯片有哪些可用的外设时钟，以及它们之间的区别。

---

## 二、时钟系统架构分析

AI8051U 的时钟系统采用**三级层次结构**：

```
时钟源(Clock Source) → 主时钟(MCLK) → 系统时钟(SYSCLK) → 外设时钟
                                  ↘ 高速I/O时钟(HSCLK) → 高速外设时钟
```

### 2.1 时钟源（6种可选）

| 时钟源 | 说明 | 频率范围 |
|--------|------|----------|
| **HIRC** (内部高速IRC) | 出厂校准的高精度内部振荡器 | 4个频段: 6M/10M/27M/44M中心频率, ±27%可调 |
| **XOSC** (外部高速晶振) | 通过 P5.6/P5.7 外接 | 用户自行选择 |
| **X32K** (外部32KHz晶振) | 通过 P5.7 外接 | 32.768KHz |
| **IRC32K** (内部32K低速IRC) | 内部低速振荡器 | ~32KHz |
| **IRC48M** (内部48M USB专用IRC) | 独立于HIRC的USB专用振荡器 | 48MHz |
| **PLL** (内部锁相环) | 可输出96MHz或144MHz | 输入时钟×PLL倍频 |

### 2.2 主时钟 MCLK 选择

由 **CLKSEL** 寄存器 (7EFE00H) 的 `MCK2SEL[1:0]` 和 `MCKSEL[1:0]` 共同决定：

- **MCKSEL[1:0]** 选择基础时钟源: HIRC / XOSC / X32K / IRC32K
- **MCK2SEL[1:0]** 可进一步切换为: MCKSEL所选 / PLL输出 / PLL/2 / IRC48M

### 2.3 系统时钟 SYSCLK

**SYSCLK = MCLK / CLKDIV**

由 **CLKDIV** 寄存器 (7EFE01H) 分频，范围 1~255。CPU和大部分常规外设使用 SYSCLK。

### 2.4 高速I/O时钟 HSCLK

由 **HSIOCK** 位(CLKSEL.6) 选择：

| HSIOCK | 高速I/O时钟源 | 最高频率 |
|--------|--------------|---------|
| 0 | 主时钟 **MCLK** | 与MCLK同频 |
| 1 | **PLL输出** (96/144MHz) | 144MHz |

HSCLK 经过 **HSCLKDIV** 寄存器 (7EFE0BH) 分频（1~255）后供给高速外设。

## 三、各外设时钟详解（核心内容）

### 3.1 系统级时钟

| 外设/功能 | 时钟源 | 控制寄存器 | 地址 | 说明 |
|-----------|--------|-----------|------|------|
| **CPU / 系统时钟** | MCLK → CLKDIV → SYSCLK | CLKDIV | 7EFE01H | 分频范围 1~255 |
| **主时钟输出脚** | MCLK → MCLKODIV | MCLKOCR | 7EFE07H | 7位分频(1~128), 输出到P4.7或P5.6 |
| **USB时钟** | HIRC / PLL/2 (48M) / IRC48M / SYSCLK | USBCLK + IRCBAND | 多处 | USB需要48MHz±精度 |
| **看门狗** | SYSCLK → WDT_PS | WDT_CONTR | C1H | 分频: 2^WDT_PS (2~256), 基础时钟=SYSCLK/12/32768 |

### 3.2 定时器时钟

| 外设 | 时钟源 | 说明 |
|------|--------|------|
| **定时器T0/T1** | SYSCLK (可选分频) | 经典8051定时器，4种模式 |
| **定时器T2** | SYSCLK | 16位自动重载 |
| **定时器T3/T4** | SYSCLK | 24位（8位预分频+16位重载），有独立预分频寄存器TM3PS/TM4PS |
| **定时器T11** | SYSCLK | 24位（8位预分频+16位重载），有独立预分频寄存器T11PS |
| **RTC实时时钟** | X32K (外部32768Hz晶振) 或内部IRC | 独立RTC模块 | 年/月/日/时/分/秒，休眠时可继续工作(仅需1.5μA) |

**重要区别**：定时器T0~T4/T11 时钟源来自 SYSCLK（即CPU同频分频），而 RTC 使用独立的 32KHz 时钟域，可在主时钟停振状态下继续工作。

### 3.3 高速外设时钟（可独立于CPU频率）

这是 AI8051U 最大的特色——**高速外设可以使用与CPU不同的时钟源**：

| 外设 | 时钟来源 | 分频寄存器 | 地址 | 最高频率 | 注意事项 |
|------|----------|-----------|------|---------|---------|
| **SPI** | HSCLK | SPI_CLKDIV | 7EFE90H | HSCLK/1 | 可配置为普通SPI或高速SPI(HSSPI) |
| **PWMA** (高级PWM-A组) | HSCLK | PWMA_CLKDIV | 7EFE91H | HSCLK/1 | **最高144MHz** |
| **PWMB** (高级PWM-B组) | HSCLK | PWMB_CLKDIV | 7EFE92H | HSCLK/1 | **最高144MHz** |
| **TFPU** (三角函数浮点单元) | HSCLK | TFPU_CLKDIV | 7EFE93H | HSCLK/1 | **最高108MHz**，也可选择PLL异步时钟 |
| **I2S** (音频总线) | HSCLK | I2S_CLKDIV | 7EFE94H | HSCLK/1 | 可使用PLL高速时钟 |

**HSCLK分频系数**：所有分频寄存器值 0=÷1, 1=÷1, 2=÷2, 3=÷3, ... 255=÷255

**HSCLK时钟源选择**（CLKSEL.6 HSIOCK位）：
- `HSIOCK=0`：HSCLK = MCLK（与系统时钟同源，仅分频不同）
- `HSIOCK=1`：HSCLK = PLL输出（96MHz或144MHz）

### 3.4 独立分频的外设时钟

| 外设 | 时钟源 | 控制方式 | 说明 |
|------|--------|----------|------|
| **I2C** | SYSCLK | I2CCFG + I2CPSCR | 总线速度 = SYSCLK/2/(MSSPEED×2+4)，最快SYSCLK/8 |
| **UART串口1~4** | SYSCLK | 通过定时器1/2做波特率发生器 | T1/T2时钟源为SYSCLK |
| **PCA** | SYSCLK (可配置分频) | CMOD寄存器的CPS[3:0] | 12种分频选项 + 定时器0溢出 |
| **高级PWM内部时钟** | fMASTER (=HSCLK经PWMA/PWMB_CLKDIV后) | PWMA_CR1/PWMB_CR1 | 内部时钟 + 预分频器(PSC) |
| **ADC** | SYSCLK | ADC_CONTR | 转换时钟=SYSCLK/分频 |
| **SPI (标准模式)** | SYSCLK | SPCTL | 速度=SYSCLK/分频 |
| **QSPI** | SYSCLK | QSPI相关寄存器 | 四线SPI |
| **HSPWM** (高速高级PWM) | HSCLK (可选PLL) | HSPWMn_CFG | 异步高速模式 |
| **TFT彩屏接口** | HSCLK | LCMIFPSCR | 时钟预分频 |
| **单总线(1-Wire)** | SYSCLK | OWPSCR | 时序控制 |

### 3.5 PLL时钟源的外设（异步高速模式）

以下外设**可以使用PLL高速时钟（独立于CPU时钟）**作为时钟源：

| 外设 | PLL作为时钟源 | 手册章节 |
|------|--------------|---------|
| **HSPWM** (高速高级PWM) | ✅ 可使用PLL高速时钟 | 第31章 (页1453) |
| **I2S** (音频总线) | ✅ 可使用PLL高速时钟 | 第35章 (页1589) |
| **TFPU** (浮点运算器) | ✅ 可选择PLL时钟异步于CPU | 第37章 (页1606, 37.8节) |

## 四、区别总结

### 4.1 核心区别：时钟域分离

AI8051U 最关键的设计是**两个独立的时钟域**：

| 时钟域 | 时钟源 | 用途 | 频率范围 |
|--------|--------|------|----------|
| **SYSCLK域** | MCLK → CLKDIV | CPU、定时器、UART、I2C、PCA、ADC、标准SPI、GPIO | 1KHz~48MHz |
| **HSCLK域** | MCLK或PLL → HSCLKDIV | 高速PWM、高速SPI、TFPU、I2S、HSPWM | 最高144MHz |

**这意味着**：
- CPU可以跑在较低的频率（如12MHz省电），同时PWMA/PWMB可以使用PLL的144MHz进行高精度PWM控制
- 高速外设时钟可以比系统时钟快很多

### 4.2 外设时钟源对照表

| 外设 | 时钟域 | 独立分频 | 可用高速PLL |
|------|--------|----------|-----------|
| CPU | SYSCLK | CLKDIV | ✅(MCK2SEL可切换到PLL) |
| T0/T1/T2/T3/T4/T11 | SYSCLK | 预分频器(部分) | ❌ |
| RTC | X32K/IRC32K (独立) | - | ❌ |
| UART1~4 | SYSCLK | 通过T1/T2 | ❌ |
| I2C | SYSCLK | I2CCFG+I2CPSCR | ❌ |
| PCA | SYSCLK | CMOD.CPS[3:0] | ❌ |
| 标准SPI | SYSCLK | SPCTL | ❌ |
| ADC | SYSCLK | ADC_CONTR | ❌ |
| WDT | SYSCLK | WDT_PS[2:0] | ❌ |
| **高速SPI** | **HSCLK** | **SPI_CLKDIV** | **✅** |
| **PWMA** | **HSCLK** | **PWMA_CLKDIV** | **✅** |
| **PWMB** | **HSCLK** | **PWMB_CLKDIV** | **✅** |
| **TFPU** | **HSCLK** | **TFPU_CLKDIV** | **✅** |
| **I2S** | **HSCLK** | **I2S_CLKDIV** | **✅** |
| **HSPWM** | **HSCLK** | **HSPWMn_CFG** | **✅** |
| TFT彩屏 | HSCLK | LCMIFPSCR | ✅ |
| 主时钟输出 | MCLK | MCLKOCR.MCLKODIV | - |
| USB | PLL/2 或 IRC48M 或 SYSCLK | USBCLK | - |

### 4.3 关键寄存器速查

| 寄存器 | 地址 | 功能 |
|--------|------|------|
| CLKSEL | 7EFE00H | 系统/主/高速时钟源选择 |
| CLKDIV | 7EFE01H | 系统时钟分频(MCLK→SYSCLK) |
| HSCLKDIV | 7EFE0BH | 高速I/O时钟分频 |
| SPI_CLKDIV | 7EFE90H | SPI外设时钟分频 |
| PWMA_CLKDIV | 7EFE91H | PWMA外设时钟分频 |
| PWMB_CLKDIV | 7EFE92H | PWMB外设时钟分频 |
| TFPU_CLKDIV | 7EFE93H | TFPU外设时钟分频 |
| I2S_CLKDIV | 7EFE94H | I2S外设时钟分频 |
| MCLKOCR | 7EFE05H | 主时钟输出控制 |
| USBCLK | - | USB时钟控制 |
| IRCBAND | 9DH | IRC频段+USB时钟选择 |

## 五、使用建议

1. **常规应用**：使用默认的 HIRC 作为 SYSCLK，CLKDIV=0，所有外设共享同一时钟
2. **高速PWM需求**：CPU跑在HIRC(如27MHz)，同时开启PLL(144MHz)→HSIOCK=1，PWMA_CLKDIV设置合适分频
3. **低功耗场景**：CPU使用IRC32K作为SYSCLK，RTC使用X32K独立运行
4. **USB通信**：USB必须48MHz，选择PLL/2、IRC48M或SYSCLK(需正好48MHz)
5. **TFPU加速**：可让TFPU独立使用PLL异步时钟(108MHz以下)，CPU继续跑自己的频率

---

> **注意**：所有 XFR 寄存器(地址7EFE00H及以上)访问前必须先使能 EAXFR=1 或 P_SW2|=0x80
