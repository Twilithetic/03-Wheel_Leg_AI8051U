## 1. 这个版本是啥？

这是一次**重大升级**！核心变化：**从"手动写代码"到"图形化配置+自动生成代码"**。类似 STM32CubeMX 的理念，但针对 STC 单片机。

## 3. 新功能详解

### 3.1 🎨 图形化 I/O 配置（核心新功能！）

```
点一点鼠标 → 配置好 GPIO → 自动生成初始化代码
```

- 可视化 IO 端口配置界面（鼠标点击选择引脚）
- 支持多选（鼠标点 P0.0, P0.3, P0.6 → 一起配置）
- 自动生成 `PxM0`, `PxM1` 等寄存器初始化代码

### 3.2 🧩 各功能模块智能化配置

| 模块 | 能配置什么 |
|------|----------|
| **GPIO** | 输入/输出/准双向/推挽/开漏/高阻 |
| **UART** | 波特率、数据位、停止位、printf 重定向、中断 |
| **定时器** | 定时器0~4 模式、时钟输出、预分频 |
| **SPI** | 主/从模式、时钟频率、引脚映射 |
| **I2C** | 主/从模式、速度配置 |
| **PWM** | 高级 PWM 通道、频率、死区 |
| **ADC** | 通道选择、转换速度 |
| **CAN** | 报文类型、滤波器配置 |
| **LIN** | （新增） |
| **QSPI** | （新增） |
| **USB** | CDC/HID 模式、不停电下载 |

### 3.3 🚀 一键生成 Keil 项目

```
配置所有外设 → 点击生成 → 自动打开 Keil → 编译 0 Error！
```

- 自动生成 `main.c`（含所有外设初始化代码）
- 自动创建 Keil 项目文件
- 重新生成时**保留用户自己写的代码**（在 `User Sources` 区域）
- 支持 32 位（C251）和 8 位（C51）模式

### 3.4 📦 程序框架自动生成

```c
// AiCube 自动生成的 main.c 模板:
void main(void)
{
    EAXFR = 1;      // 允许访问扩展 SFR
    WTST = 0;       // 全速
    CKCON = 0;
    
    GPIO_init();    // ← 自动生成
    UART1_init();   // ← 自动生成
    Timer0_init();  // ← 自动生成
    // ... 你配的所有外设
    
    EA = 1;
    
    while(1)
    {
        // 你的业务代码放这里
    }
}
```

## 4. 和你现在的开发方式对比

| | 现在（手动） | AiCube（自动生成） |
|------|----------|-----------------|
| GPIO | 手写 `P0M1=0; P0M0=0;` × 8 | 鼠标点一点 ✅ |
| UART | 手算波特率 → 配 SCON/TMOD | 下拉选波特率 ✅ |
| 定时器 | 手算预分频 → 写 TH0/TL0 | 图形化配置 ✅ |
| printf | 需要自己写 putchar | 勾选即可 ✅ |
| 不停电下载 | 需要手动加 USB 库 | 勾选自动加 ✅ |
| 代码生成 | 全手写 | **一键生成 0 Error** ✅ |
