# P3.0/P3.1 双重身份详解：USB vs UART

> 来源：AI8051U 官方手册第 291、332-335 页

---

## 1. 一个引脚，三重身份

手册第 332 页明确标注了引脚功能：

```
P3.0  =  D-  /  RxD  /  INT4
P3.1  =  D+  /  TxD
```

| 引脚 | 功能 1（USB） | 功能 2（UART） | 功能 3（中断） |
|------|-------------|---------------|--------------|
| **P3.0** | D-（USB 差分负极） | RxD（串口接收） | INT4（外部中断 4） |
| **P3.1** | D+（USB 差分正极） | TxD（串口发送） | — |

---

## 2. 怎么做到一个引脚两个功能？

### 2.1 硬件层面：内部有两条电路

```
                    P3.0 引脚（物理焊盘）
                         │
            ┌────────────┼────────────┐
            │            │            │
            ▼            ▼            ▼
      ┌──────────┐ ┌──────────┐ ┌──────────┐
      │ USB PHY  │ │ UART 模块│ │ GPIO 逻辑│
      │ (差分收发)│ │ (串口)   │ │ (普通IO) │
      └──────────┘ └──────────┘ └──────────┘
            │            │            │
            └────────────┼────────────┘
                         │
                  芯片内部总线
```

**芯片内部有独立的 USB PHY（物理层收发器）和 UART 控制器**，它们共享同一个引脚焊盘。通过内部寄存器切换，决定哪个模块连接到引脚。

物理上：
- USB D-/D+ 需要**差分信号**（两条线电压差表示数据），需要特殊的模拟电路
- UART RxD/TxD 是**单端数字信号**（一条线高低电平表示数据），普通数字 IO

> 💡 STC 把 USB 收发器直接做进了芯片（不需要外部 PHY 芯片），所以同一个引脚可以对外呈现为 USB 差分对或普通 GPIO。

### 2.2 Bootloader 层面：自动检测！

手册第 291 页的关键说明：

> "当用户程序软复位到系统区时，**若 P3.0/D- 和 P3.1/D+ 已经和电脑的 USB 口相连**，则系统代码**会自动进入 USB 下载模式**等待 ISP 下载"

```
ISP 监控程序启动
       │
       ▼
┌──────────────────┐
│  检测 P3.0/P3.1  │
└──────┬───────────┘
       │
  ┌────┴────┐
  │         │
  ▼         ▼
检测到 USB  没检测到 USB
  │         │
  ▼         ▼
USB-HID    UART 模式
模式       监听 0x7F
(VID=34BF, (1200bps)
 PID=1001)
```

**Bootloader 不是"同时使用"两个功能，而是"先检测再选择"：**

1. 先看看 USB D+/D- 有没有连接（USB 有上拉电阻特征）
2. 如果 USB 连着 → 用 USB-HID 模式烧录
3. 如果 USB 没连着 → 回退到 UART 模式，监听串口命令流

## 3. USB-HID vs UART：同一套引脚的不同协议

```
        USB-HID 模式                     UART 模式
        ────────────                     ────────
    P3.0 ←──→ D-                    P3.0 ←── RXD (收)
    P3.1 ←──→ D+                    P3.1 ──→ TXD (发)

    协议:  USB 2.0 FS              协议: 异步串行
    包格式: HID Report (64B)        包格式: 字节流 + ISP 命令
    速度: ~64KB/s                   速度: 1200~115200 bps
    工具: STC-ISP HID 模式          工具: STC-ISP 串口模式
```

---

## 4. 三种常见使用场景

| 场景 | P3.0 | P3.1 | 用什么 |
|------|------|------|--------|
| **USB 烧录**（你在用） | D- | D+ | USB 线直连电脑 |
| **串口烧录** | RxD | TxD | USB-TTL 模块 |
| **用户程序用串口通信** | RxD | TxD | 代码中配 UART |
| **用户程序用 USB-CDC** | D- | D+ | 虚拟串口，免驱动 |

---

## 5. AI8051U 的 USB 外设在用户程序中也能用！

手册第 332-335 页说明，AI8051U 在**用户程序**中也能使用 USB，STC 提供了官方的 USB 库：

| 库 | 用途 |
|-----|------|
| **USB-CDC 库** | 虚拟串口（速度快，Win10+ 免驱动） |
| **USB-HID 库** | 免驱动数据通信（64KB/s，所有 Windows 免驱动） |

下载链接：https://www.stcaimcu.com/data/download/Library/STC_USB_LIBRARY.zip

## 6. 总结

| 问题 | 答案 |
|------|------|
| P3.0/P3.1 为什么能当 USB 用？ | 芯片内置 USB PHY，不需要外部芯片 |
| 为什么还能当 UART 用？ | 内部有两套独立电路，通过寄存器切换 |
| Bootloader 怎么选？ | **自动检测**——USB 连着就用 HID，没连着就回退 UART |
| 能同时用吗？ | ❌ 不能同时，只能二选一 |
| P3.0 的第三个功能？ | INT4（外部中断 4） |

---

*💕 一句话：P3.0/P3.1 就像瑞士军刀——芯片内置 USB 收发器和 UART 控制器，通过内部开关选择连哪个。Bootloader 更聪明，上电时自动检测：USB 插着就用 HID 烧录，没插就监听串口。*
