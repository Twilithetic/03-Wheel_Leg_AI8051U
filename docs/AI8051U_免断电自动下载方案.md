## 2. 原理（手册第 291 + 318 页）

芯片在运行用户程序时，通过 **USB-HID 通信**持续监听 ISP 下载命令。收到命令后通过 `IAP_CONTR = 0x60` 软件复位到 ISP 区。

```
你的程序 (main.c)                          AiCube ISP
     │                                        │
     │  初始化 USB-HID                         │
     │  开始监听下载命令                        │
     │        │                                │
     │   ┌────▼────┐                          │
     │   │ 正常跑    │                          │
     │   │ LED 闪烁  │       编译完成            │
     │   │ 定时器   │  ←─── HEX 变了! ──────── │
     │   └────┬────┘                          │
     │        │             发送 "@STCISP#"       │
     │   ┌────▼────┐  ←───── 或自定义命令 ──── │
     │   │ 收到命令! │                          │
     │   │ IAP_CONTR │                          │
     │   │  = 0x60  │                          │
     │   └────┬────┘                          │
     │        │                                │
     │   ┌────▼────┐                          │
     │   │ CPU 复位  │  ─────── USB-HID ─────→ │ 自动开始烧录!
     │   │ 进入 ISP  │                          │
     │   └─────────┘                          │
```

## 3. 两种方案

### 方案 A：USB-HID 模式（⭐推荐，手册第 292 页）

适合你的场景——板子通过 USB 直连。

**Step 1**: 在代码中嵌入 USB-HID 监听

需要 STC 官方的 `stc_usb_hid.lib` 库。已经在 `libs/STC_USB_LIBRARY.zip` 里。

```c
#include "AI8051U.h"

// ===== USB-HID 自动下载代码（来自 STC 官方库） =====
// 关键：初始化 USB-HID 并监听下载命令
// 收到命令后自动 IAP_CONTR = 0x60

// 详细代码参考：
// libs/STC_USB_LIBRARY.zip 解压后的 STC-HID 范例程序

// 简化示例:
#include "stc_usb_hid.h"   // STC 官方 USB-HID 库

void sys_init(void)
{
    // ... GPIO 初始化 ...
    
    // 初始化 USB-HID
    usb_init();            // USB 库初始化
    
    EA = 1;                // 开中断
}

void main(void)
{
    sys_init();
    
    while(1)
    {
        // 正常程序逻辑
        // USB-HID 的下载命令检测在中断中处理
        // 无需在 main 循环中额外处理
    }
}
```

**Step 2**: AiCube ISP 设置（手册第 292 页）

```
1. 打开 AiCube ISP
2. 打开 "收到用户命令后复位到 ISP 监控程序区" 选项页
3. 选择 "USB(HID)模式"
4. VID 填 "34BF"，PID 填 "FF01" (或 1001)
5. 设置自定义下载命令 (如 "@STCISP#")
6. 勾选 "当目标文件变化时自动装载并发送下载命令"
7. 勾选 "目标文件变化后自动开始下载"
```

**效果**：
```
编译 → ISP 自动检测 HEX 变化 → 发送命令 → 芯片复位 → 烧录完成 🔥
        全程零手动！
```

### 方案 B：UART 模式（手册第 318 页）

需要串口连接，**不适合你**（你用的是 USB 直连）。

```c
// 串口监听 @STCISP# 命令（仅 UART 模式）
char code *STCISPCMD = "@STCISP#";
char index = 0;

void uart_isr() interrupt 4
{
    if (RI)
    {
        RI = 0;
        if (SBUF == STCISPCMD[index])
        {
            index++;
            if (index == 8)  // "@STCISP#" 共 8 个字符
            {
                IAP_CONTR = 0x60;  // 复位到 ISP！
            }
        }
        else
        {
            index = 0;
        }
    }
}
```

## 6. 如果不想改代码（折中方案）

用 **P3.2 按键触发软件复位**（手册第 291 页，方法一）：

```c
// 超级简单的方案：按下 P3.2 就复位到 ISP
#include "AI8051U.h"

void main(void)
{
    // ... 初始化 ...
    
    while(1)
    {
        // 只需要加这几行！
        if (P32 == 0)              // P3.2 被按下（接地）
        {
            delay_ms(50);           // 去抖
            if (P32 == 0)
            {
                IAP_CONTR = 0x60;  // 复位到 ISP
            }
        }
        
        // 正常程序... LED 闪烁等
    }
}
```

这样只需要按一下板子上的 P3.2 按键（不需要断电！），然后在 AiCube ISP 中勾选 "目标文件变化后自动开始下载"。
