## 一、上电复位 → 第一条指令

```
VCC 上电 (3.3V / 5V)
  │
  ├─ ① 内部 HIRC 起振（默认 ~6MHz）
  │
  ├─ ② 等待时钟稳定（IRCDB 控制，默认等 128 个时钟）
  │    手册 §10.2.2: IRCDB 上电复位初始值 = 80H → 等待 127 个时钟
  │
  ├─ ③ Flash 存储器唤醒
  │    手册 §10.2.1: 需要 1μs 时基，由 IAP_TPS 设置
  │    → 必须设置 IAP_TPS = SYSCLK(MHz)，否则 Flash 读取出错！
  │
  ▼ ④ 复位释放！CPU 开始工作
```

### 复位后 CPU 的状态

| 寄存器 | 复位值 | 含义 |
|--------|:------:|------|
| **PC** | **FF:0000h** | 🔴 程序计数器指向复位入口 |
| WTST | 1（默认） | Flash 访问需等待 1 周期 |
| CKCON | 0000x000B | XDATA 访问速度默认值 |
| SYSCLK | ~6MHz | 默认 HIRC 频率 |
| EAXFR | 0 | XFR 空间锁死 |
| EA | 0 | 全局中断关闭 |
| SP | 07h | 堆栈指针初值 |

> **关键**：WTST、CKCON、SYSCLK 在复位后都是默认值！
> 你的 `SYS_Init()` 跑完之后才变成"最快模式"。

```
Flash 地址空间 (64KB 主区域, FF:0000h - FF:FFFFh)
┌──────────────────────────────────┐
│ FF:0000h  🔴 复位入口             │  LJMP main
│ FF:0003h  外部中断 0 (INT0)       │
│ FF:000Bh  定时器 0 (T0)           │
│ FF:0013h  外部中断 1 (INT1)       │
│ FF:001Bh  定时器 1 (T1)           │
│ FF:0023h  串口 1 (UART1)         │
│ FF:002Bh  ADC 中断               │
│ FF:0033h  LVD 中断               │
│ FF:003Bh  PCA 中断               │
│ FF:0043h  串口 2 (UART2)         │
│ FF:004Bh  SPI 中断               │
│ FF:0053h  外部中断 2 (INT2)       │
│ FF:005Bh  外部中断 3 (INT3)       │
│ FF:0063h  定时器 2 (T2)           │
│ FF:0073h  预留                    │
│ FF:007Bh  定时器 11 (T11)         │
│ FF:0083h  ...更多扩展中断         │
│  ...                             │
│  你的 main() 代码                 │
│  你的 ISR 代码                    │
│  库函数代码                       │
│  ...                             │

```

**Keil 编译器自动做的事**：
- 在 FF:0000h 放一条跳转指令 → 跳到你的 `main()`
- 每个中断向量处放一条跳转指令 → 跳到对应的 ISR
- 你没写的中断，编译器放一条 `RETI`（直接返回）

## 三、WTST 寄存器详解

### 3.1 寄存器定义

```c
// AI8051U.H:449
sfr WTST = 0xe9;    // 程序读取等待控制寄存器
                    // 位于标准 SFR 空间，不需要 EAXFR

// ai8051u_def.h:1154-1155
#define AccessCodeSpeed(n)    WRITE_REG(WTST, (n))
#define AccessCodeFastest()   AccessCodeSpeed(0)
```

### 3.2 作用

```
CPU 从 Flash 取指令的时序:

时钟:  ┌─┐  ┌─┐  ┌─┐  ┌─┐  ┌─┐
       │ │  │ │  │ │  │ │  │ │
       ┘ └──┘ └──┘ └──┘ └──┘

WTST=0: [取][取][取][取][取]  ← 每个周期都能取 ⚡
WTST=1: [取][等][取][等][取]  ← 一半时间在等
WTST=2: [取][等][等][取][等]  ← 更慢
```

**WTST 控制的是 Flash 存储器输出数据后、CPU 锁存数据前，需要插多少个空时钟。**

### 3.3 为什么需要等待？

Flash 存储器的**访问时间**有物理上限：
- AI8051U 内部 Flash：典型访问时间约 20~25ns
- 如果 SYSCLK = 40MHz（周期 25ns），Flash 刚好够用 → WTST=0
- 如果 SYSCLK = 50MHz（周期 20ns），Flash 可能跟不上 → 需要 WTST=1

### 3.4 手册原文

来自官方手册每个示例代码的注释：

> *"WTST = 0; //设置取程序代码等待时间，*
>  *赋值为 0 表示不等待，程序以最快速度运行"*

手册 §12.1.1 专辟一节：**"程序读取等待控制寄存器（WTST）"**

## 四、取指令流程 & 流水线

### 4.1 一条指令怎么执行？

```
阶段1: 取指 (Fetch)    → 从 Flash 读指令字节
阶段2: 译码 (Decode)   → 识别这是什么指令
阶段3: 执行 (Execute)  → 完成运算/跳转/读写
```

80251 是 **3 级流水线**，三个阶段可以重叠：

```
时间 →
        周期1   周期2   周期3   周期4   周期5
指令A:  [取指]→[译码]→[执行]
指令B:         [取指]→[译码]→[执行]
指令C:                [取指]→[译码]→[执行]
指令D:                       [取指]→[译码]→...
```

**实际效果**：平均每条指令约 **1 个时钟周期**！

### 4.2 不同指令耗时

| 指令类型 | 字节数 | 周期数 | 例子 |
|---------|:---:|:---:|------|
| NOP | 1 | 1 | `_nop_()` |
| MOV A, R0 | 1 | 1 | 寄存器间传送 |
| LJMP addr16 | 3 | 2 | 长跳转 |
| MOV DPTR, #data16 | 3 | 2 | 加载立即数 |
| INC DPTR | 1 | 1 | 数据指针+1 |
| MUL AB | 1 | 5 | 8位乘法 |
| DIV AB | 1 | 5 | 8位除法 |
| MOVX @DPTR, A | 1 | 2~更多 | 写外部数据（CKCON 影响） |

## 五、CKCON 寄存器 — 数据访问速度

```c
// AI8051U.H
sfr CKCON = 0xea;

// ai8051u_def.h
#define AccessIXramFastest()     (CKCON = 0)  // XDATA 访问最快
```

### 5.1 CKCON 控制什么？

**CKCON** 控制访问 XDATA 空间（外部/内部扩展 RAM）时 CPU 需要等多少时钟。

```
MOVX @DPTR, A    // 写 XDATA
  │
  CKCON = 0 → 写操作立即完成（零等待）
  CKCON = 7 → 写操作额外等 7 个时钟（慢慢写）
```

这影响的是**数据**读写速度，不是取指令速度。

## 六、你代码中的完整启动时序

```
SYS_Init() 第 123-126 行:
┌─────────────────────────────────────────┐
│ ① EnableAccessXFR()   EAXFR=1  🔑开门   │  之后才能碰 XFR 空间寄存器
│ ② AccessCodeFastest()  WTST=0   ⚡取指快 │  之后取指令零等待
│ ③ AccessIXramFastest() CKCON=0  ⚡读写快 │  之后数据访问零等待
│ ④ IAP_SetTimeBase()    设时基   ⏱️     │  Flash 操作需要 1μs 时基
└─────────────────────────────────────────┘
         ↓
CLK_Init()  → SYSCLK: 6MHz → 36MHz(PLL)
         ↓
其他初始化 → USB/定时器/...
```

                    SYSCLK (36MHz)

    │ ≈27.8ns │    │  ≈27.8ns │    │ 1T(最快)  │

| 场景 | SYSCLK | WTST | 取一字节 | 跑 100 万条 NOP |
