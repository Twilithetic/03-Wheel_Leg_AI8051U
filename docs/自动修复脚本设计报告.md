## 2. 脚本设计

### 2.1 功能需求

```
输入: 无（自动检测 EIDE 安装目录）
输出: 所有 EIDE 版本的 C251 model 文件被修复

步骤:
  1. 自动找到所有 EIDE 安装 → C:\Users\29344\.vscode\extensions\cl.eide-*
  2. 找到每个版本下的 8051.keil.model.json
  3. 备份原文件 → 8051.keil.model.json.bak
  4. 用 C251 配置替换内容
  5. 显示结果
```

### 2.2 替换方案选择

| 方案 | 做法 | 优点 | 缺点 |
|------|------|------|------|
| **A: 字符串替换** | `-replace 'BIN/C51', '../C251/BIN/C251'` | 简单 | 可能误伤注释、容易出错 |
| **B: JSON 对象修改** ⭐ | `ConvertFrom-Json` → 改属性 → `ConvertTo-Json` | 精确、安全 | 需要理解 JSON 结构 |
| **C: 全文覆盖** | 直接写死完整 JSON | 最简单 | EIDE 升级若改结构会失效 |

**选择方案 B（JSON 对象修改）**，因为它精确、安全，且不依赖 JSON 格式细节（如缩进）。

### 2.3 具体替换内容

| 字段路径 | 原值 | 新值 |
|---------|------|------|
| `name` | `Keil C51 Compiler` | `Keil C251 Compiler` |
| `id` | `KEIL_C51` | `KEIL_C251` |
| `version.matcher` | `C51 COMPILER` | `C251 COMPILER` |
| `groups.c/cpp.$path` | `BIN/C51` | `../C251/BIN/C251` |
| `groups.asm.$path` | `BIN/A51` | `../C251/BIN/A251` |
| `groups.linker.$path` | `BIN/LX51` | `../C251/BIN/L251` |
| `groups.linker-lib.$path` | `BIN/LIBX51` | `../C251/BIN/LIB251` |
| `groups.linker.$outputBin[0].toolPath` | `BIN/Ohx51` | `../C251/BIN/OH251` |
| `groups.c/cpp.$default` | 数组（含 `OMF2`, `TABS(4)`） | 数组（仅 `CODE`, `NOCOND`, `SYMBOLS`） |
| `groups.linker` 中的 `use-RTX` | 删除 | — |

### 2.4 脚本结构

```powershell
# fix_c251_model.ps1

# 1. 定义常量
#    EIDE 扩展根目录
#    Model 文件名
#    替换映射表

# 2. 查找所有 EIDE 安装
#    Get-ChildItem cl.eide-*

# 3. 对每个安装
#    ├── 定位 model 文件
#    ├── 检查是否已被 hack
#    ├── 备份原文件 (.bak)
#    ├── JSON → 对象 → 修改属性 → JSON
#    └── 写入文件

# 4. 打印结果摘要
```

## 4. 安全措施

| 措施 | 说明 |
|------|------|
| **自动备份** | 每次修复前把原文件另存为 `.bak` |
| **幂等检查** | 如果已经是 C251 版本则跳过 |
| **错误处理** | JSON 解析失败时显示错误但不中断 |
| **彩色输出** | 绿色=成功，黄色=跳过，红色=失败 |

## 5. PowerShell 脚本速记

姐姐整理了本脚本用的 PowerShell 核心语法：

```powershell
# ---- 变量 ----
$name = "hello"              # 定义变量
$path = "C:\Users\$env:USERNAME"  # 环境变量用 $env:

# ---- 条件 ----
if ($x -eq "yes") { ... }    # -eq = 等于, -ne = 不等于
if (Test-Path $f) { ... }    # 检查路径存在

# ---- 遍历 ----
Get-ChildItem "*.json" | ForEach-Object {
    $_.FullName               # $_ = 当前对象
}

# ---- JSON ----
$obj = Get-Content file.json -Raw | ConvertFrom-Json
$obj.name = "new name"
$obj | ConvertTo-Json -Depth 10 | Set-Content file.json

# ---- 输出 ----
Write-Host "OK" -ForegroundColor Green
Write-Host "ERROR" -ForegroundColor Red

# ---- 暂停 ----
Read-Host "Press Enter to exit"
```
