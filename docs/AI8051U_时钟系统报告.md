## 3. 四种时钟源（官方确认）

| 时钟源 | 频率 | 精度 | 用途 |
|--------|------|------|------|
| **HIRC** (内部高速 RC) | 4 个频段：6M / 10M / 27M / 44M | ±0.3% (室温) | 默认系统时钟 |
| **XOSC** (外部高速晶振) | 12M~48M (取决于 XCFILTER) | ±20 ppm | 精确时序、PLL 输入 |
| **IRC32K** (内部低速) | ~32KHz（误差大，压漂温漂明显） | 低 | 低功耗模式、WDT |
| **IRC48M** (内部 48M) | 48MHz | ±1% | USB 时钟 |

### 3.1 上电默认

```
上电复位 → ISP 监控程序 → 固定使用内部 24MHz HIRC
            ↓
      下载完成后复位 → 默认使用上次 ISP 下载时调节的 HIRC 频率
```

### 3.2 外部晶振（P5.6/P5.7）— 官方接线图

```
          ┌──────────────┐
  P5.7 ───┼─┬───────────┤  XTALI
          │ │  外部晶振   │
          │ ├─[▒▒▒]────┤
  P5.6 ───┼─┴───────────┤  XTALO
          │    ┌─┤├─┐   │
          │    │ C1 │   │  C1,C2 = 20~47pF
          │    └────┘   │  (高速晶振推荐 47pF)
          │    ┌─┤├─┐   │  (32K晶振 ≤20pF)
          │    │ C2 │   │
          │   GND ─────┤
          └──────────────┘

  抗干扰建议:
  - XTALI 串 200Ω 电阻 → 有利于起振
  - XTALO 串 1KΩ 电阻  → 减少电磁辐射
```

**手册原话**：
> "一般不需外部晶振，我司内部高速 HIRC 时钟完全满足串口通讯需求"

## 4. ⭐ 关键发现：AI8051U 有 PLL！

### 4.1 PLL 参数

| 参数 | 值 |
|------|-----|
| PLL 输出 | **96MHz** (CKMS=0) 或 **144MHz** (CKMS=1) |
| PLL 输入 | 必须约 **12MHz**（范围 8~16M） |
| 输入预分频 | PCKI[1:0] = /1, /2, /4, /8 |
| 选择来源 | CLKSEL.MCKSEL[1:0] → HIRC/XOSC/X32K/IRC32K |

### 4.2 PLL 使用场景

```
普通模式:   HIRC(24M) → CLKDIV → SYSCLK(≤42M)
高性能:     HIRC(24M) → PLL → 96M/144M → CLKDIV → SYSCLK(≤42M)
USB 模式:   IRC48M → USB 时钟(48M) 
            (或 PLL/2 → USB 时钟)
```

**注意**：AI8051U 的**系统时钟最高 42MHz**，PLL 产生的 96/144MHz 是给**高速外设**用的（PWM 可达 144MHz，SPI 可达 33MHz）。

## 5. 寄存器完整列表（官方手册第 542 页）

### 5.1 标准 SFR

| 寄存器 | 地址 | 关键位 |
|--------|------|--------|
| **IRCBAND** | 0x9D | SEL[1:0]：频段选择 (6M/10M/27M/44M)；USBCKS：USB时钟选择 |
| **IRTRIM** | 0x9F | 256 级频率微调，每级约 0.24% |
| **USBCLK** | 0xDC | ENCKM：PLL倍频使能；PCKI[1:0]：PLL输入分频 |
| **WTST** | 0xE9 | 程序等待周期 (0=最快) |
| **CKCON** | 0xEA | xdata 访问速度 |

### 5.2 扩展 XRAM 寄存器

| 寄存器 | 地址 | 功能 |
|--------|------|------|
| **CLKSEL** | 0x7EFE00 | ⭐ 时钟源选择（主时钟 + 高速外设） |
| **CLKDIV** | 0x7EFE01 | ⭐ 系统时钟分频 (1~255) |
| **HIRCCR** | 0x7EFE02 | HIRC 使能 + 稳定标志 |
| **XOSCCR** | 0x7EFE03 | 外部晶振使能 + 类型 + 增益 + 稳定标志 |
| **IRC32KCR** | 0x7EFE04 | 32K IRC 使能 + 稳定标志 |
| **MCLKOCR** | 0x7EFE05 | 主时钟输出 (P4.7 或 P5.6) |
| **IRCDB** | 0x7EFE06 | 省电模式唤醒等待时钟数 |
| **IRC48MCR** | 0x7EFE07 | 48M IRC 使能 + 稳定标志 |
| **X32KCR** | 0x7EFE08 | 外部 32K 晶振使能 + 稳定标志 |
| **HSCLKDIV** | 0x7EFE0B | 高速外设时钟分频 (1~255) |

### 5.3 外设独立时钟分频器

| 寄存器 | 地址 | 外设 | 时钟源 |
|--------|------|------|--------|
| **SPI_CLKDIV** | 0x7EFE90 | SPI | HSCLK |
| **PWMA_CLKDIV** | 0x7EFE91 | PWM A 组 | HSCLK (≤144MHz) |
| **PWMB_CLKDIV** | 0x7EFE92 | PWM B 组 | HSCLK (≤144MHz) |
| **TFPU_CLKDIV** | 0x7EFE93 | TFPU | HSCLK (≤108MHz) |
| **I2S_CLKDIV** | 0x7EFE94 | I2S | HSCLK |

## 6. 咱项目的时钟分析

```c
// main.c
WTST  = 0x00;    // 等待周期 0 → CPU 全速
CKCON = 0x00;    // xdata 访问全速
// 没有设置 CLKSEL / CLKDIV → 使用默认值
```

| 参数 | 值 |
|------|-----|
| 时钟源 | **HIRC**（默认 24MHz，出厂校准） |
| 频段 | 27M 频段 |
| 主时钟 MCLK | 24 MHz |
| 分频 CLKDIV | 1 (默认不分频) |
| 系统时钟 SYSCLK | **24 MHz** |
| 等待周期 WTST | 0 (全速) |
| PLL | 未启用 |

> 💡 `WTST=0` 表示"程序以最快速度运行"。24MHz 下 Flash 可以跟上，不需要等待。

## 7. 如何切换时钟频率（官方范例）

### 7.1 切换到外部晶振

```c
EAXFR = 1;                    // 允许访问扩展寄存器
WTST = 0; CKCON = 0;          // 最快速度
// ... GPIO 初始化 ...

XOSCCR = 0xC0;                // 启动外部晶振
while (!(XOSCCR & 1));        // 等待频率稳定
CLKDIV = 0x00;                // 不分频
CLKSEL = 0x01;                // 选择外部晶振
while (1);
```

### 7.2 动态切换不同的 HIRC 频率

芯片出厂时预置了多种频率的校准值（存储在 CHIPID11~CHIPID20），可以直接调用：

```c
// 切换到 24MHz:
CLKDIV = 0x04;                // 先分频降速
IRTRIM = CHIPID12;            // 加载 24MHz 校准值
VRTRIM = CHIPID23;            // 加载 27M 频段校准值
IRCBAND &= ~0x03;
IRCBAND |= 0x02;              // 选 27M 频段
CLKDIV = 0x00;                // 恢复全速
```

支持的预置频率：22.1184M / 24M / 27M / 30M / 33.1776M / 35M / 36.864M / 40M / 44.2368M / 48M
