# AI8051U 定时器 & 1秒精确 LED 闪烁报告

> **报告时间**：2026-04-29
> **数据来源**：`资料_芯片外设_AI8051U芯片手册.pdf` 第 17 章（第 866-920 页）

---

## 1. 先回答：你的 Delay500ms 准吗？

```c
// 当前的延时（软件延时）
void Delay500ms(void) {
    unsigned long edata i;
    _nop_(); _nop_();
    i = 1382398UL;
    while (i) i--;
}
```

**不准！** 原因：
- 软件延时依赖编译器生成的指令数，**优化级别不同会导致延时不同**
- 中断打断会导致延时变长
- 温度变化对内部 RC 时钟有影响（±1% 温漂）
- `1382398UL` 这个数是怎么算出来的？可能只是目测的 😅

> 💡 **要用硬件定时器 + 中断，才能精确到微秒级！**

## 2. AI8051U 有哪些定时器？

### 2.1 总共 6 个！

| 定时器 | 寄存器 | 特点 |
|--------|--------|------|
| **T0** | TH0, TL0 (8A/8C) | 4 种模式，16 位 + 8 位预分频 = 24 位 |
| **T1** | TH1, TL1 (8B/8D) | 3 种模式，通常留给 UART 波特率 |
| **T2** | T2H, T2L (D6/D7) | 16 位自动重载，8 位预分频 |
| **T3** | T3H, T3L (D4/D5) | 16 位，8 位预分频 |
| **T4** | T4H, T4L (D2/D3) | 16 位，8 位预分频 |
| **T11** | T11H, T11L | 16 位，8 位预分频 |

### 2.2 T0 的 4 种工作模式

| 模式 | TMOD | 特性 |
|------|------|------|
| **模式 0** | `M1M0=00` | ⭐ 16 位自动重装载（推荐！） |
| 模式 1 | `M1M0=01` | 16 位不自动重装载 |
| 模式 2 | `M1M0=10` | 8 位自动重装载 |
| 模式 3 | `M1M0=11` | 16 位 + **不可屏蔽中断**（RTOS 用） |

### 2.3 1T vs 12T 模式

| 模式 | 寄存器 | 速度 |
|------|--------|------|
| **1T** (推荐) | `AUXR.T0x12 = 1` | 每个系统时钟计数一次 |
| 12T | `AUXR.T0x12 = 0` | 每 12 个系统时钟计数一次 |

## 3. 如何实现精确 1 秒？

### 3.1 计算公式（来自手册第 879 页）

```
定时器周期 = SYSclk ÷ (TM0PS + 1) ÷ (65536 - [TH0, TL0])

其中:
  SYSclk    = 系统时钟（咱项目 24MHz）
  TM0PS     = 8 位预分频器（0~255）
  [TH0,TL0] = 16 位重装载值（自动重载模式下）
```

### 3.2 设计思路

用 T0 产生 **10ms 中断**，软件计数 100 次 = 1 秒：

```
24MHz ÷ 12（预分频）÷ 20000（重载值）= 100Hz → 10ms
      ↑ TM0PS = 11         ↑ 65536 - 20000 = 45536

中断每 10ms 触发一次
软件计数器 cnt 从 0 累加到 100 → 1 秒到！
翻转 LED
```

### 3.3 完整代码（用 T0 实现精确 1s LED 闪烁）

```c
#include "AI8051U.h"

// ==================== 全局变量 ====================
unsigned int tick_ms = 0;     // 毫秒计数器（每 10ms +1）

// ==================== T0 初始化 ====================
void Timer0_Init(void)
{
    // 1. 设置 T0 为模式 0（16 位自动重装载）
    TMOD &= 0xF0;              // 清除 T0 控制位
    TMOD |= 0x00;              // T0_M1=0, T0_M0=0 → 模式0
                               // GATE=0, C/T=0 → 定时器模式
    
    // 2. 设置重装载值（10ms @ 24MHz, TM0PS=11）
    //    SYSclk/(TM0PS+1) = 24MHz/12 = 2MHz
    //    计数到 20000 溢出 → 20000/2MHz = 10ms
    //    65536 - 20000 = 45536 = 0xB1E0
    TL0 = 0xE0;                // 低字节
    TH0 = 0xB1;                // 高字节
    
    // 3. 设置预分频器 TM0PS = 11（即 ÷12）
    EAXFR = 1;                 // 允许访问扩展寄存器
    TM0PS = 11;                // 8 位预分频器：0~255
    EAXFR = 0;
    
    // 4. 设置为 1T 模式（不分频，速度最快）
    AUXR |= 0x80;              // T0x12 = 1 → 1T 模式
    
    // 5. 使能 T0 中断
    ET0 = 1;                   // 允许 T0 中断
    EA = 1;                    // 开总中断
    
    // 6. 启动 T0
    TR0 = 1;                   // T0 开始计数
}

// ==================== T0 中断服务程序 ====================
void Timer0_ISR(void) interrupt 1
{
    tick_ms += 10;             // 每 10ms 累加
    
    if (tick_ms >= 1000)       // 1 秒到了！
    {
        tick_ms = 0;
        P42 = ~P42;            // 翻转 LED
    }
}

// ==================== 主函数 ====================
void main(void)
{
    // GPIO 初始化
    P0M1=0;P0M0=0; P1M1=0;P1M0=0;
    P2M1=0;P2M0=0; P3M1=0;P3M0=0;
    P4M1=0;P4M0=0; P5M1=0;P5M0=0;
    P6M1=0;P6M0=0; P7M1=0;P7M0=0;
    P42 = 0;                   // LED 初始灭
    
    WTST = 0x00;               // 全速运行
    
    Timer0_Init();             // 启动定时器
    
    while(1)
    {
        // 主循环什么也不做，LED 由中断控制
        // 可以在这里放其他任务
    }
}
```

## 6. 总结

| 问题 | 答案 |
|------|------|
| AI8051U 有定时器吗？ | ✅ 6 个！T0~T4 + T11 |
| Delay500ms 准吗？ | ❌ 不准，建议用硬件定时器 |
