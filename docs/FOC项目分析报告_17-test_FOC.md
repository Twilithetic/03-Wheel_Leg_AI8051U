## 3. FOC 类型与原理

### 3.1 该项目的 FOC 属于哪种？

本项目实现的是 **基于传感器的磁场定向控制（Sensored Field-Oriented Control）**，也称为：

- **有传感器 FOC**（与无传感器 FOC / Sensorless FOC 相对）
- **基于磁编码器的 FOC**（使用 AS5600 获取转子角度）
- **电流闭环 FOC**（使用 INA199A1 + 采样电阻检测三相电流）

### 3.2 FOC 基本原理

> 💡 **一句话概括**：把三相交流电机的控制，通过数学变换"降维"成类似直流电机的控制——分别控制"励磁电流"和"力矩电流"。

#### 核心概念：从三相到两相旋转坐标

```
     物理世界（三相静止）         数学世界（两相旋转）
    ┌───────────────────┐     ┌───────────────────┐
    │   A 相电流  Ia    │     │                    │
    │   B 相电流  Ib    │ ──→ │  Id（励磁电流）     │
    │   C 相电流  Ic    │     │  Iq（力矩电流）     │
    └───────────────────┘     └───────────────────┘
         ↑                           ↑
    交流，随转子旋转            直流，可独立控制
```

**为什么这样做？**
- 三相交流电机的电流是交变的，直接控制非常困难
- 通过坐标变换，把交流量变成直流量，就可以用经典的 PID 控制器来分别控制
- **Id = 0** 控制策略：让励磁电流为零，所有电流用于产生力矩（最大力矩/电流比，MTPA）

#### 变换步骤

```
第 1 步：Clarke 变换（3 相静止 → 2 相静止）
  Iα = Ia - 0.5·Ib - 0.5·Ic
  Iβ = (√3/2)·Ib - (√3/2)·Ic
  目的：去掉冗余的一相（3 相中只有 2 相独立）

第 2 步：Park 变换（2 相静止 → 2 相旋转）
  Id = Iα·cos(θ) + Iβ·sin(θ)
  Iq = -Iα·sin(θ) + Iβ·cos(θ)
  目的：把交流量"冻结"成直流量（跟着转子一起转）

第 3 步：PID 控制（在 d-q 旋转坐标系中）
  Vd = PID(Id_ref, Id_meas)   ← 控制励磁电流
  Vq = PID(Iq_ref, Iq_meas)   ← 控制力矩电流

第 4 步：逆 Park 变换（2 相旋转 → 2 相静止）
  Vα = Vd·cos(θ) - Vq·sin(θ)
  Vβ = Vq·cos(θ) + Vd·sin(θ)
  目的：从旋转坐标系"解冻"回静止坐标系

第 5 步：逆 Clarke 变换（2 相静止 → 3 相静止）
  Va = Vα
  Vb = (√3·Vβ - Vα) / 2
  Vc = (-Vα - √3·Vβ) / 2
  目的：恢复到 3 相电压，输出给电机驱动器
```

#### 该项目的 SVPWM / 电压输出方式

值得注意的是，本项目**使用了简单的 SPWM（正弦 PWM）而不是 SVPWM（空间矢量 PWM）**：
- 逆 Clarke 变换后直接得到 3 相电压值 `Va, Vb, Vc`
- 将电压值线性映射到 ePWM 的比较值寄存器
- 没有实现 7 段式或 5 段式 SVPWM 调制
- 这在低电压（12.6V）应用中影响不大，因为电压利用率不是瓶颈

### 4.2 核心器件详解

#### 🔴 主控芯片：TMS320F280049C

| 参数 | 详情 |
|------|------|
| 架构 | C28x 32-bit DSP + CLA 协处理器 |
| 主频 | 100 MHz（20MHz 晶振 × 10 / 2） |
| FPU | FPU64（硬件浮点，支持 64-bit double） |
| TMU | 三角函数硬件加速器（sin/cos 仅需几个时钟周期） |
| ADC | 3 个 12-bit ADC，最高 3.5 MSPS |
| ePWM | 8 个模块，每模块 2 路输出（A/B） |
| Flash | 256 KB |
| RAM | 100 KB |

> **关键优势**：FPU64 + TMU 硬件加速使得 FOC 中的浮点运算（三角函数、坐标变换）极其高效，**不需要定点数近似**。

#### 🔵 电机驱动器：DRV8313

| 参数 | 详情 |
|------|------|
| 类型 | 3 相半桥集成 MOSFET 驱动器 |
| 最大电压 | 60V |
| 最大电流 | 2.5A 峰值 / 1.75A RMS |
| PWM 频率 | 最高 250 kHz |
| 控制方式 | 3 路 PWM 输入（6 个 MOSFET 内部互补生成） |
| 保护功能 | 过流、过热、欠压锁定 |

- 使用 3 路 ePWM 输出分别控制 OUT1/OUT2/OUT3
- 每路 ePWM 配置为**互补输出模式**（A 路直通，B 路互补）
- 使能信号：GPIO30(EN1)、GPIO58(EN2)、GPIO25(EN3)

#### 🟢 电流传感器：INA199A1 + 采样电阻

| 参数 | 详情 |
|------|------|
| 传感器型号 | INA199A1（固定增益 50V/V） |
| 采样电阻 | R_shunt = 0.02 Ω（20 mΩ） |
| 参考电压 | V_ref = 1.65V（3.3V 的中点） |
| ADC 参考 | 3.3V（12-bit → 0~4095） |

**电流计算公式**（源码 `INA199A1.c` 行 44-55）：
```
V_out = ADC_value × (3.3V / 4096)                         // ADC 值 → 电压
V_shunt = (V_out - V_ref) / 50                            // 去除增益
I_phase = V_shunt / 0.02  ≈ V_shunt × 50                 // 欧姆定律
```

简化后：
```
I_phase = (ADC_value - 2048) × 3.3 / (4096 × 50 × 0.02)
        = (ADC_value - 2048) × 0.000805
```

- 零偏自动校准：上电时采集 1000 个样本取平均作为零点偏移
- 检测范围：约 ±8A（受限于 3.3V 摆幅和增益）

#### 🟡 角度传感器：AS5600

| 参数 | 详情 |
|------|------|
| 类型 | 12-bit 非接触式磁编码器（Hall 效应） |
| 分辨率 | 4096 位置/圈（0.088°/步） |
| 接口 | I2C（地址 0x36，400kHz） |
| 角度范围 | 0° ~ 360°（可编程最大角度 18°~360°） |
| 输出模式 | I2C RAW 数据 / PWM 波 / 模拟电压 |
| 更新时间 | 约 920 μs（I2C 读取） |

**多圈累计**（源码 `AS5600.c` 行 99-120）：
- 检测角度跨越 2π 边界（0° ↔ 360°）
- 自动累计圈数，实现多圈绝对位置跟踪
- 速度计算：`ω = (θ_curr - θ_prev) / Δt`（通过 CPU Timer2 时间戳）

### 6.2 FOC 控制流水线（`FOC_Mode.c`）

```c
// 每个控制周期（1ms 定时器中断触发）：

Step 1:  FOC_Updata_Measure_data()
         ├── INA199A1: 读 3 相电流（ADC 采样 + 校准转换）
         └── AS5600:   读转子角度（I2C）+ 速度计算

Step 2:  FOC_Update_Current_Elec_Rad_Torque_From_Measure_Data()
         ├── Clarke 变换:   Ia,Ib,Ic → Iα,Iβ
         ├── 电角度计算:    θ_elec = θ_mech × 7（极对数）
         └── Park 变换:     Iα,Iβ,θ_elec → Id,Iq

Step 3:  Filter_LPF_Apply_In_FOC_current_D_Q_torque()
         └── 一阶低通滤波 Id 和 Iq

Step 4:  PID_Updata_Current_D_Q_Torque_To_Vlot_D_Q_Torque()
         ├── D 轴 PID:  Id_ref(通常=0) → Vd
         └── Q 轴 PID:  Iq_ref → Vq（产生力矩）

Step 5:  FOC_Update_three_phase_vlot_From_vlot_Elec_Rad_Torque()
         ├── 逆 Park 变换:  Vd,Vq,θ_elec → Vα,Vβ
         └── 逆 Clarke 变换: Vα,Vβ → Va,Vb,Vc

Step 6:  _FOC_three_phrase_Result_to_Drv8313()
         └── Va,Vb,Vc → ePWM 比较值 → DRV8313 输出
```

### 6.3 三级 PID 控制结构

```
┌─────────────────────────────────────────────────────┐
│            角度环 PID（最外层）                       │
│  输入: 目标角度 θ_ref vs 实际角度 θ_meas             │
│  输出: 目标速度 ω_ref                                │
│  Kp=10, Kd=1                                        │
├─────────────────────────────────────────────────────┤
│            速度环 PID（中间层）                      │
│  输入: 目标速度 ω_ref vs 实际速度 ω_meas             │
│  输出: 目标力矩电流 Iq_ref                           │
│  Kp=0, Ki=1 (纯积分控制)                            │
├─────────────────────────────────────────────────────┤
│            电流环 PID（最内层）                      │
│  ┌──────────────┐    ┌──────────────┐               │
│  │ D 轴电流 PID  │    │ Q 轴电流 PID  │               │
│  │ Id_ref = 0   │    │ Iq_ref → Vq  │               │
│  │ Kp=10, Ki=50 │    │ Kp=10,Ki=100 │               │
│  │ 输出范围 ±2.6V│   │ 输出范围 ±2.6V│              │
│  └──────────────┘    └──────────────┘               │
└─────────────────────────────────────────────────────┘
                        │
                        ▼
                  Vd, Vq → 逆 Park → ePWM
```

**级联控制的好处**：
- 电流环最快（~kHz 级别），保证力矩响应
- 速度环次之，实现平滑调速
- 位置环最慢，实现精确定位
- 每层都可以独立调参和限幅

## 7. 关键算法实现细节

### 7.1 坐标变换源码（`FOC_Trans.c`）

#### Clarke 变换（行 37-38）
```c
// 3 相 → α-β 静止坐标系
I_α = I_a - 0.5f * I_b - 0.5f * I_c;
I_β = (√3/2) * I_b - (√3/2) * I_c;
```

#### Park 变换（行 49-51）
```c
// α-β 静止 → d-q 旋转坐标系
I_d = I_α * cosf(θ_elec) + I_β * sinf(θ_elec);
I_q = -I_α * sinf(θ_elec) + I_β * cosf(θ_elec);
```

#### 逆 Park 变换（行 66-67）
```c
// d-q 旋转 → α-β 静止坐标系
V_α = V_d * cosf(θ_elec) - V_q * sinf(θ_elec);
V_β = V_q * cosf(θ_elec) + V_d * sinf(θ_elec);
```

#### 逆 Clarke 变换（行 75-77）
```c
// α-β 静止 → 3 相电压
V_a = V_α;
V_b = (√3 * V_β - V_α) / 2;
V_c = (-V_α - √3 * V_β) / 2;
```

#### 电角度计算（行 84）
```c
// 机械角度 → 电角度（乘以极对数）
θ_elec = θ_mech * Pole_Pairs;  // Pole_Pairs = 7
// 然后归一化到 [0, 2π)
```

> ⚠️ **注意**：F280049C 的 TMU（三角函数加速器）硬件可以极快地计算 `sinf()` 和 `cosf()`（2-3 个时钟周期），这使得浮点 FOC 在 100MHz DSP 上毫无压力。

### 7.2 PID 控制器（`FOC_PID.c`）

每个 PID 控制器结构体包含：
```c
typedef struct {
    float Kp, Ki, Kd;              // PID 参数
    float error, error_prev;       // 当前/上次误差
    float integral;                // 积分累计
    float output, output_max, output_min; // 输出 + 限幅
    float dT;                      // 采样时间
} PIDController;
```

**抗积分饱和（Anti-Windup）**：通过 `output_max` / `output_min` 限幅实现。

**采样时间计算**：通过 CPU Timer2 自由运行计数器的差值计算 `dT`。

### 7.3 低通滤波器（`FOC_Filter.c`）

一阶指数平滑滤波器：
```
Value_filtered = α × Value_raw + (1 - α) × Value_filtered_prev
```
其中 α（滤波系数）越小，滤波越强（响应越慢）。

## 8. 与当前 AI8051U 项目的对比

### 8.1 芯片对比

| 特性 | **TMS320F280049C**（原项目） | **AI8051U**（当前项目） |
|------|---------------------------|------------------------|
| 架构 | C28x 32-bit DSP（Harvard） | Intel 80251（32 位 8051 扩展） |

| TMU | ✅ 硬件三角函数加速器 | ❌ 需要查表或软件计算 |
| ADC | 3× 12-bit, 3.5 MSPS | ✅ 12-bit ADC，但速度和通道数受限 |
| PWM | 8× ePWM 模块（16 位高精度） | ✅ 增强型 PWM（PWMA），精度待确认 |
| 定时器 | 3× 32-bit CPU Timer + eCAP | T0/T1(16-bit) + T2/T3/T4(16-bit) |

| RAM | 100 KB | 待确认（较小） |
| Flash | 256 KB | 待确认（较小） |
| 开发工具链 | TI CCS + SysConfig | Keil C251 |
| 调试接口 | JTAG (XDS110) | USB 直接仿真 / SWD (不推荐) |

### 8.2 关键差距

| 差距维度 | 说明 |
|----------|------|
| **浮点算力** | 这是最大的差距。F280049C 有硬件 FPU64+TMU，FOC 中每次控制周期需要 8+ 次 `sinf/cosf` 和数十次浮点乘除。AI8051U 用软件浮点可能远不能满足实时性需求。 |
| **PWM 精度** | ePWM 支持 16-bit 高分辨率模式（HRPWM），AI8051U 的 PWMA 需要确认是否支持足够的精度和死区控制。 |
| **ADC 速度** | F280049C 的 ADC 非常快（3.5 MSPS），可以在 PWM 周期内完成多通道采样。AI8051U 的 ADC 转换速度需确认。 |
| **定时中断** | F280049C 用 1ms 定时器中断触发 FOC 控制循环。AI8051U 需要配置等效的定时中断。 |

## 9. 移植可行性分析

### 9.1 结论：可以直接移植吗？

**⚠️ 不完全可以直接移植。** 核心挑战在于浮点算力。

如果目标是 **移植 FOC 控制算法到 AI8051U**，有以下路径：

### 9.2 移植方案

#### 方案 A：定点数 FOC（推荐 ✅）

将浮点运算全部转换为定点数（Q 格式），这是 8051 平台实现 FOC 的经典做法：

- `sin/cos` → 查表（256 点或 512 点正弦表，线性插值）
- 浮点乘除 → Q15/Q24 定点乘除
- PID 计算 → 定点 PID（注意溢出和截断）
- **优点**：能在 8051 上跑，性能可控
- **缺点**：代码改动大，调试困难，精度有损失

**参考资源**：
- AN1078：Microchip 的 "Sensorless FOC for PMSM Using dsPIC" 使用了 Q15 定点数实现
- VESC 开源电调的部分定点实现

#### 方案 B：协处理器方案（🚀 未来可考虑）

使用 AI8051U 的 32-bit 模式 + 知识库中的 DSP 协处理方案，或者外挂一个专用的 FOC 协处理器：
- 例如 TI 的 MCF8315D（内置 FOC 算法的全集成功率驱动器）

#### 方案 C：上位机 FOC + 底层 PWM 驱动

在 AI8051U 上只做：
1. AS5600 角度读取（I2C）
2. 电流 ADC 采样
3. 数据打包上传（USB/串口）
4. PC 端做 FOC 计算，下发 PWM 占空比

这是最简单的验证方案，适合先跑通硬件链路。

### 9.3 外设映射（F280049C → AI8051U）

| F280049C 外设 | 功能 | AI8051U 等效 | 可行性 |
|--------------|------|-------------|--------|
| ePWM1/2/3 ×6 | 6 路互补 PWM | PWMA 6 通道 | ✅ 需配置死区 |
| ADCA ×3 SOC | 3 相电流采样 | ADC 3 通道 | ✅ 需确认速度 |
| GPIO 软件 I2C | AS5600 角度 | GPIO 软件 I2C | ✅ 直接移植 |
| SCI UART | 调试输出 | UART1 | ✅ 直接移植 |
| CPU Timer 1ms | FOC 定时中断 | Timer0 中断 | ✅ 需配置 |
| CPU Timer2 | 自由计数器 | Timer1 连续计数 | ✅ 直接映射 |

## 10. 总结与建议

### 10.1 项目亮点

1. **完整的 FOC 实现**：从传感器到 PWM 输出的完整闭环，代码结构清晰
2. **多控制模式**：电压/力矩/速度/位置四种模式，方便分阶段调试
3. **详细的注释**：中文注释非常详尽，解释了每个变换的物理意义
4. **硬件自校准**：电流传感器自动校零，编码器多圈累计
5. **模块化设计**：Hardware/Software 分层，同一套 FOC 算法可复用

### 10.2 需要注意的问题

1. ⚠️ **没有 SVPWM**：使用的是简单 SPWM，电压利用率约 86.6%（和母线电压 12.6V 相比，影响不大）
2. ⚠️ **没有过流保护**：虽然有硬件限流（DRV8313），但软件层面缺少快速过流关断
3. ⚠️ **PID 参数简陋**：Kp=10, Ki=100 这类参数看起来像经验值，缺少系统性的参数整定（如 Ziegler-Nichols 或频域分析）
4. ⚠️ **只支持 Id=0 控制**：没有弱磁控制（Field Weakening），高速性能受限
5. ⚠️ **软件 I2C**：用 GPIO 位操作模拟 I2C，效率低（每次通信占用 CPU），建议转移到硬件 I2C

### 10.3 对当前项目的建议

| 优先级 | 建议 | 理由 |
|--------|------|------|
| 🥇 | **先用方案 C 验证硬件链路** | AI8051U 采集传感器数据 + PC 端 FOC 计算，快速验证电机/传感器/驱动器是否正常工作 |
| 🥈 | **评估 AI8051U 定点 FOC 性能** | 在确认硬件正常后，尝试定点数 FOC，测试一个控制周期需要多长时间 |
| 🥉 | **调研 AS5600 替代方案** | 如果 I2C 速度是瓶颈，可以考虑霍尔传感器 + ADC 方式获取角度 |
| 🔮 | **长远考虑专用 FOC 芯片** | 如果 AI8051U 算力确实不够，可以用 MCF8315D 等全集成功率级+接口通信 |
