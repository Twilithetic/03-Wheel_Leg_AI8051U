## 2. 外设清单

> 以下信息来自 `AI8051U.H` 头文件（976行寄存器定义）、STC 手册及网络资料

### 2.1 GPIO（通用输入输出）

| 端口 | 引脚数 | 说明 |
|------|--------|------|
| P0 | 8 位 | 标准 IO |
| P1 | 8 位 | 标准 IO |
| P2 | 8 位 | 标准 IO |
| P3 | 8 位 | 标准 IO + UART1 / 外部中断 / USB D+/D- |
| P4 | 8 位 | 扩展 IO |
| P5 | 8 位 | 扩展 IO |
| P6 | 8 位 | 扩展 IO |
| P7 | 8 位 | 扩展 IO |

**每个 GPIO 支持 4 种模式**：
- 准双向口（传统8051模式）
- 推挽输出
- 开漏输出
- 高阻输入

配置寄存器：`PxM0`, `PxM1`（x=0~7）

**附加特性**（通过扩展 XRAM 寄存器）：
- 内部上拉电阻 (`PxPU`)
- 施密特触发 (`PxNCS`)
- 驱动能力 (`PxDR`)
- 边沿检测 / 数字输入 (`PxIE`)
- 下拉电阻 (`PxPD`)

### 2.2 定时器/计数器

| 定时器 | 位数 | 说明 |
|--------|------|------|
| **T0** | 16 位 | 标准 8051 Timer0 |
| **T1** | 16 位 | 标准 8051 Timer1 |
| **T2** | 16 位 | 增强 Timer2 |
| **T3** | 16 位 | 增强 Timer3 |
| **T4** | 16 位 | 增强 Timer4 |
| **T11** | 16 位 | 附加 16 位定时器（RTC 相关） |
| **WDT** | — | 看门狗定时器 |

特殊功能：
- `T0x12`, `T1x12` 等：选择 1T/12T 模式
- `T0CLKO`, `T1CLKO` 等：时钟输出
- 每个定时器可配置预分频器 (`TM0PS`~`TM4PS`)

### 2.3 串行通信

| 外设 | 数量 | 关键特性 |
|------|------|---------|
| **UART1** | 1 组 | 全功能，波特率时钟可达 FOSC/4 |
| **UART2** | 1 组 | USART2 |
| **UART3** | 1 组 | USART3 |
| **UART4** | 1 组 | USART4 |
| **SPI** | 1 组 | 主/从模式，可自动切换 |
| **I2C** | 1 组 | 主/从模式 |
| **I2S** | 1 组 | 数字音频接口 |
| **CAN** | 2 组 | CAN + CAN2（CAN-FD 可选） |
| **LIN** | 1 组 | LIN 总线 |
| **USB** | 1 组 | USB 2.0 Device（D+/D- 在 P3.0/P3.1） |

UART 引脚可重映射（通过 `P_SW1`, `P_SW2` 寄存器）。

### 2.4 模拟外设

| 外设 | 规格 |
|------|------|
| **ADC** | **12 位**，最高 **16 通道**，速度达 30 万次/秒 |
| **比较器 (CMP)** | 1 组，可用作简易 ADC |
| **内部参考电压** | 内置 Bandgap 参考源 |
| **DAC** | 无独立 DAC，PWM 可作 D/A 替代 |

### 2.5 高级 PWM

| PWM 模块 | 通道 | 位数 |
|----------|------|------|
| **PWMA** | CH1~CH4 | 16 位高级 PWM |
| **PWMB** | CH5~CH8 | 16 位高级 PWM |

特性：
- **死区控制**（互补输出 + 死区时间）
- 外部故障检测
- 6/7/8/10/15 位 PWM 模式
- 时钟预分频

### 2.6 其他外设

| 外设 | 说明 |
|------|------|
| **RTC** | 实时时钟，支持年月日时分秒 + 闹钟 |
| **LCMIF** | LCD 控制器接口（支持 8080 总线） |
| **CRC** | 硬件 CRC 校验 |
| **DMA** | 直接存储器访问（`DMAIR` 寄存器） |
| **外部中断** | INT0~INT4，共 5 个外部中断源 |
| **低电压检测 (LVD)** | 中断 + 复位，4 级阈值可选 |
| **PCA/CCP** | 4 组（CCP0~CCP3），支持捕获/比较/PWM |

### 2.7 时钟系统

| 时钟源 | 说明 |
|--------|------|
| **内部 HIRC** | 24MHz ±0.3%（可微调） |
| **内部 IRC32K** | 32KHz 低功耗时钟 |
| **内部 IRC48M** | 48MHz（USB 专用） |
| **外部晶振** | 4~33MHz（可接） |
| **外部 32K** | 32.768KHz（RTC 使用） |
| **PLL** | 通过 `MCLKOCR` 配置系统时钟分频 |

## 3. 烧录方式

### 3.1 烧录方式总览

| 方式 | 接口 | 工具 | 说明 |
|------|------|------|------|
| **UART ISP** | P3.0(RXD) + P3.1(TXD) | USB-TTL 模块 + STC-ISP | 经典方式，最通用 |
| **USB-HID** ⭐ | USB D+/D- (P3.0/P3.1) | STC-ISP（AiCube ISP） | AI8051U 支持！无需 UART 转换器 |
| **USB-CDC** | USB D+/D- | STC-ISP | 虚拟串口模式 |
| **U8W 烧录器** | 专用烧录座 | U8W / U8W-Mini | 离线批量烧录 |
| **USB-Link1D** | USB | Link1D + STC-ISP | 在线/离线烧录 + 仿真 |

### 3.2 烧录原理（ISP）

STC 芯片的 ISP 流程：

```
1. 芯片上电 → 检测是否接收到 ISP 握手信号
     ↓ 是
2. 进入 ISP 模式（执行内置 Bootloader）
     ↓
3. 通过 UART/USB 接收 HEX 数据
     ↓
4. 写入 Flash → 软复位 → 运行用户程序
```

**关键时序**：必须在**上电瞬间**检测到 ISP 信号。正确操作顺序：

> **先点"下载/编程"→ 再给芯片上电（或冷启动）**

而不是先上电再点下载。

### 3.3 USB-HID 烧录（⭐ 推荐用于 AI8051U）

你的板子被识别为 HID 设备，这正是 AI8051U 的 USB 直连烧录模式！

| 步骤 | 操作 |
|------|------|
| 1 | 用 USB 线连接板子和电脑（D+/D- 接 P3.0/P3.1） |
| 2 | 打开 STC-ISP（AiCube ISP） |
| 3 | 选择芯片型号：**AI8051U-34K64** |
| 4 | 打开 HEX 文件 |
| 5 | 选择 **USB-HID 模式**（或自动检测） |
| 6 | 点击"下载/编程" |
| 7 | 给板子断电再上电（冷启动） |

> 🔑 **关键**：AI8051U 烧录时需要在 STC-ISP 中选择 **C51 还是 C251 指令集模式**（因为芯片支持双模式）。

### 3.4 UART 烧录（传统方式）

如果不想用 USB-HID，也可以接 USB-to-UART：

```
USB-TTL 模块         AI8051U 板
   TX     ─────────→  RXD (P3.0)
   RX     ─────────→  TXD (P3.1)
   GND    ─────────→  GND
   +5V    ─────────→  VCC  (或板子独立供电)
```

需要安装 CH340/CH341 等 USB 转串口驱动。

### 3.5 烧录保护引脚

AI8051U（STC15 及之后的新芯片）使用 **P3.2 和 P3.3** 作为烧录保护引脚：
- 烧录时 P3.2=0, P3.3=0 才能进入 ISP 模式
- 如果被用户程序占用，可在 STC-ISP 中勾选"下次冷启动时 P3.2/P3.3 为 0/0 才可下载"

## 4. 烧录工具

### 4.1 STC-ISP（AiCube ISP）— 官方工具

| 项目 | 说明 |
|------|------|
| **当前版本** | v6.96S（2026） |
| **语言** | 中文/英文 |
| **特性** | 烧录、串口助手、代码生成、头文件导出、EEPROM 编辑 |
| **项目已有** | `docs/AiCube-ISP-v6.95Z.exe` |

### 4.2 开源工具

| 工具 | 支持 | 说明 |
|------|------|------|
| **stcgal** | UART | Python 开源烧录工具，支持 Linux/Mac/Windows |
| **stcflash.py** | UART | 轻量 Python 脚本（项目已有），仅支持 COM 口 |

> ⚠️ `stcflash.py` 和 `stcgal` 暂不支持 USB-HID 模式。AI8051U 用 USB-HID 烧录只能用官方 STC-ISP。

## 5. 与外设对应的寄存器区域

从 `AI8051U.H` 分析：

| 寄存器区域 | 地址范围 | 内容 |
|-----------|---------|------|
| **标准 SFR** | 0x80~0xFF | P0~P7, 定时器, UART, 中断等 |
| **扩展 XRAM 0** | 0x7E:FE00~0x7E:FEFF | 时钟配置、GPIO 增强、RTC、I2C、SPI 时钟 |
| **扩展 XRAM 1** | 0x7E:FD00~0x7E:FDFF | GPIO 中断、PCA、I2S、CRC、DMA |
| **扩展 XRAM 2** | 0x7E:FC00~0x7E:FCFF | USART1~4 增强配置 |
| **芯片 ID** | 0x7E:FDE0~0x7E:FDFF | 芯片唯一 ID |

访问扩展 XRAM 需先设置 `P_SW2 |= 0x80`（EAXFR=1）。

## 6. 你的烧录问题解决方案

```
当前情况：
  AI8051U 板子 USB 直连 → 被识别为 HID 设备
  stcflash.py → 找不到 COM3 → 失败 ❌

解决方案：
  方案一：用 STC-ISP（AiCube ISP）USB-HID 模式烧录 ✅
    文件：docs/AiCube-ISP-v6.95Z.exe
  
  方案二：外接 USB-TTL 转换器 + UART 烧录
    需装 CH340 驱动 → stcflash.py 可用
```
