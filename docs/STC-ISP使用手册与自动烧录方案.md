
## 2. STC-ISP 能自动烧录吗？

### 2.1 结论：软件本身**不能**完全自动化

STC-ISP 是一个 **GUI 程序**，没有命令行模式，没有 API。但可以通过**硬件 + 软件配合**实现半自动化。

### 2.2 三种自动化方案

| 方案 | 原理 | 难度 | 效果 |
|------|------|------|------|
| **A. 硬件自动冷启动** | CH340G 的 DTR/RTS 控制电源 | ⭐ | 免手动断电 |
| **B. 软件自动复位 (ADOS)** | 代码中监听 ISP 命令流，自动跳转 | ⭐⭐ | 完全免断电 |
| **C. 离线烧录器** | U8W/U8W-Mini 批量烧录 | ⭐ | 适合生产 |

---

## 3. 方案 A：硬件自动冷启动（最常用）

### 3.1 原理

CH340G 等 USB 转串口芯片的 **DTR** 或 **RTS** 引脚可以控制 MCU 的电源：

```
         CH340G                      MCU
    ┌──────────────┐          ┌──────────────┐
    │ DTR ────┬────┼───→     │ VCC          │
    │         │    │          │              │
    │ RXD ────┼────┼───→ TXD │ P3.1         │
    │ TXD ←───┼────┼─── RXD │ P3.0         │
    │         │    │          │              │
    │     ┌───┴──┐ │          │              │
    │     │ PNP  │ │          │              │
    │     │ 三极管│ │          │              │
    │     └──────┘ │          │              │
    └──────────────┘          └──────────────┘

   STC-ISP 点下载 → DTR 拉低 → 三极管导通 → MCU 断电
           下载开始 → DTR 恢复 → 三极管截止 → MCU 上电（冷启动！）
```

### 3.2 需要什么

- 开发板上带 CH340G + 自动冷启动电路（很多 STC 开发板自带）
- 在 STC-ISP 中勾选"使用 DTR 控制下载"

### 3.3 效果

```
之前:  点下载 → 手动拔插 USB → 等待
现在:  点下载 → 自动冷启动 → 烧录完成 ✅
```

**仍然需要手动点"下载"按钮。**

## 4. 方案 B：软件自动复位（ADOS — Auto Download Of STC）⭐

### 4.1 原理

在用户程序中嵌入一段代码，**持续监听串口**，一旦收到 STC-ISP 发出的 `0x7F` 命令流，就通过 IAP 功能跳转到 ISP 监控程序区：

```c
// 嵌入到你的 main.c 中
void check_isp_command(void)
{
    // 如果串口收到了连续的 0x7F（STC-ISP 的握手信号）
    // 就通过 IAP 复位到 ISP 模式
    if (received_isp_handshake)
    {
        IAP_CONTR = 0x60;  // 软件复位到 ISP 区
    }
}
```

### 4.2 完整工作流

```
1. 在 VSCode 中写代码
2. Ctrl+Shift+B 编译
3. 打开 STC-ISP → 加载 HEX → 点下载
4. 串口发出 0x7F → MCU 检测到 → 自动跳转 ISP → 烧录完成 ✅
```

### 4.3 限制

- 需要占用 **UART1**（P3.0/P3.1）来监听
- 如果项目本身要用串口，就不能用这个方案
- USB-HID 模式不支持（ADOS 只支持 UART 模式）

## 5. 方案 C：离线烧录器

### 5.1 使用 STC 官方烧录器

| 烧录器 | 说明 |
|--------|------|
| **U8W** | USB 在线/离线烧录器 |
| **U8W-Mini** | 迷你版，功能相同 |
| **USB-Link1D** | 在线烧录 + 仿真 |

### 5.2 离线烧录流程

```
1. 用 STC-ISP 把 HEX 下载到 U8W
2. U8W 脱离电脑，独立工作
3. 每次按下烧录键 → 自动烧录一颗芯片
4. 适合批量生产
```
